

# 📁 Config 디렉토리

이 디렉토리는 SignalCraft 애플리케이션의 **환경별 설정 파일**을 포함하고 있습니다.

---

## 🧭 개요

`config` 디렉토리는 개발, 테스트, 운영 등 다양한 배포 환경에서 사용되는 설정을 관리하기 위한 **환경별 구성 파일**을 담고 있습니다.

---

## 📂 포함된 파일

- `database.env` – 데이터베이스 연결 설정  
- `database.env.template` – 데이터베이스 환경 변수 템플릿

---

## 🔄 설정 로딩 흐름

```
애플리케이션 시작
        ↓
환경 감지 (dev / staging / prod)
        ↓
설정 파일 로딩 (config 디렉토리에서)
        ↓
환경 변수 설정
        ↓
서비스 초기화
        ↓
런타임 설정 관리
```

---

## 🎯 목적

이 디렉토리는 다음과 같은 설정 정보를 정의합니다:

- 데이터베이스 연결 파라미터  
- 환경별 애플리케이션 설정  
- 외부 서비스 인증 정보  
- 애플리케이션 전반의 구성 값

---

## 🌎 환경 설정

`.env` 파일은 민감한 정보와 환경별 변수들을 저장하며, **저장소에 커밋되지 않아야 합니다.**  
`*.template` 파일은 필요한 환경 변수의 구조를 제공하여 설정을 쉽게 구성할 수 있도록 돕습니다.

---

## 🧱 설정 계층 구조

```
기본 설정 (하드코딩) → 환경 파일 (config/) → 런타임 오버라이드 → 활성 설정
```

---

## ⚙️ 환경 설정 흐름

```
개발 환경 구성 → 설정 검증 → 서비스 설정 → 연결 테스트 → 준비 완료
```

---

## 🔐 보안 주의사항

설정 파일에는 데이터베이스 자격 증명, API 키, 기타 보안 정보가 포함될 수 있습니다.  
이 파일들은 반드시 **보안적으로 안전하게 관리**되어야 하며, **공개 저장소에 노출되지 않도록 주의**해야 합니다.

---

## 🔄 설정 변경 프로세스

```
설정 변경 요청 → 검증 → 환경 업데이트 → 서비스 재시작 → 확인 → 로그 기록
```

---

## 🔗 통합 지점

- **데이터베이스 서비스**: 연결 파라미터 제공  
- **인증 서비스**: API 키 관리  
- **알림 서비스**: 웹훅 URL 설정  
- **결제 서비스**: 상점 인증 정보  
- **분석 서비스**: 추적 ID 설정
