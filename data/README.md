

# 📁 Data 디렉토리

이 디렉토리는 SignalCraft 오디오 분석 시스템의 **모든 데이터 관련 파일**을 포함하고 있습니다.

---

## 🧭 개요

`data` 디렉토리는 SignalCraft 시스템에서 사용하는 **데이터셋, 오디오 파일, 모델, 기타 데이터 자산**의 중앙 저장소 역할을 합니다.  
여기에는 학습, 테스트, AI 모델 실행에 사용되는 **원시 및 전처리된 데이터**가 모두 포함됩니다.

---

## 📂 하위 디렉토리

### 🎧 오디오 데이터

- `augmented_audio/` – 학습을 위해 증강된 오디오 파일  
- `downloaded_sounds/` – 다양한 출처에서 다운로드된 오디오  
- `high_quality_sounds/` – 고품질 참조용 오디오  
- `real_audio_uploads/` – 사용자 업로드 실시간 오디오  
- `real_sounds/` – 실제 환경에서 수집된 오디오  
- `sound_samples/` – 샘플 오디오 파일  
- `synthetic_sounds/` – 합성된 오디오 데이터

### 📊 특성 데이터

- `features/` – 분석을 위한 오디오 특성 데이터  
- `esp32_features/` – ESP32 센서로부터 수집된 특성 데이터

### 🧪 학습 데이터

- `labeling_ready/` – 라벨링 준비가 완료된 오디오  
- `synthetic_data/` – 학습용으로 생성된 합성 데이터  
- `training_data/` – AI 모델 학습을 위한 전처리된 데이터셋

### 🧠 지식 기반 데이터

- `engineer_knowledge/` – 엔지니어의 도메인 지식  
- `models/` – 학습된 모델 파일 및 관련 데이터

---

## 🗃️ 데이터베이스 파일

- `analytics.db` – 분석 및 모니터링 데이터베이스  
- `explicit_knowledge.json` – 엔지니어의 명시적 지식을 담은 JSON  
- `labeling_database.js` – 라벨링 작업을 관리하는 데이터베이스  
- `monitoring.db` – 시스템 모니터링용 데이터베이스  
- `smart_storage.db` – 일반 데이터 저장소  
- `user_permissions.db` – 사용자 권한 및 인증 정보

---

## 🔄 데이터 파이프라인 흐름

```
원시 오디오 수집 (ESP32, 사용자 업로드)
        ↓
전처리 및 특성 추출
        ↓
데이터 증강 및 합성 생성
        ↓
라벨링 (전문가 + AI 보조)
        ↓
학습 데이터셋 구성
        ↓
모델 학습
        ↓
모델 평가 및 검증
        ↓
프로덕션 배포
```

---

## 🎯 목적

이 디렉토리는 다음과 같은 역할을 수행합니다:

- 학습 및 테스트용 데이터셋 저장  
- AI 모델 파일 관리  
- 지도 학습을 위한 라벨링 데이터 관리  
- 오디오 녹음 수집 및 정리  
- 분석을 위한 특성 데이터 저장

---

## 🧩 데이터 관리 워크플로우

```
데이터 수집 → 검증 → 전처리 → 저장 구조화 → 접근 제어 → 사용 추적
```

## 📚 데이터 흐름 유형

### 📘 학습 데이터 흐름

```
원시 오디오 → 전처리 → 특성 추출 → 라벨링 → 학습 데이터 → 모델 학습 → 검증
```

### 📡 실시간 데이터 흐름

```
ESP32 센서 → 데이터 수집 → 전처리 → 특성 추출 → 모델 추론 → 결과 출력
```

### 🧬 합성 데이터 생성

```
엔지니어 지식 → 합성 데이터 생성 → 검증 → 학습 데이터 증강
```

---

## 🔗 통합 지점

- AI 서비스: 모델 학습 및 추론  
- ESP32 센서: 실시간 데이터 수집  
- 라벨링 도구: 데이터 주석 작업  
- 분석 서비스: 데이터 인사이트 제공  
- 모델 관리 서비스: 모델 배포 및 버전 관리

---

## 🗂️ 데이터 관리 전략

이 디렉토리는 다양한 유형의 데이터를 체계적으로 구성하여,  
**데이터 수집부터 모델 배포까지의 머신러닝 파이프라인**을 효율적으로 관리할 수 있도록 설계되었습니다.
