# 🧾 Templates 디렉터리

이 디렉터리는 SignalCraft 웹 애플리케이션의 서버 측 템플릿을 포함하고 있습니다.

## 🧭 개요
Templates 디렉터리는 서버에서 렌더링되어 동적 웹 페이지를 생성하는 HTML 템플릿들을 담고 있습니다. 이 템플릿들은 템플릿 문법을 사용하여 동적 데이터를 삽입하고, 사용자와 상호작용할 수 있는 UI를 구성합니다.

## 📁 디렉터리 구조
- `admin/` - 관리자 인터페이스용 템플릿  
- `customer/` - 고객 인터페이스용 템플릿  

### 루트 파일
- `faq.html` - 자주 묻는 질문(FAQ) 페이지 템플릿  
- `login.html` - 로그인 페이지 템플릿  
- `showcase.html` - 쇼케이스 페이지 템플릿  

## 🔄 페이지 렌더링 흐름
```
요청 → 라우터 → 컨트롤러 → 데이터 조회 → 템플릿 엔진 → HTML 생성 → 정적 자산 포함 → 클라이언트 응답
```

## 🎯 목적
이 템플릿들은 다음을 위한 기반 역할을 합니다:
- 서버 렌더링 HTML 페이지
- 동적 콘텐츠 표시
- 사용자 인터페이스 구성 요소
- 관리자 대시보드
- 고객용 페이지
- 인증 인터페이스

## 📂 템플릿 분류

### 🛠️ 관리자 템플릿
```
관리자 요청 → 관리자 템플릿 → 관리자 데이터 → 관리자 UI → 관리 인터페이스
```

### 👤 고객 템플릿
```
고객 요청 → 고객 템플릿 → 고객 데이터 → 고객 UI → 고객 인터페이스
```

### 🔐 인증 템플릿
```
로그인 요청 → 로그인 템플릿 → 인증 → 세션 생성 → 대시보드 접근
```

## ✨ 템플릿 기능
- 관리자 인터페이스용 템플릿
- 고객용 페이지
- 로그인 및 인증 페이지
- FAQ 섹션
- 쇼케이스 요소
- 반응형 디자인 요소

## ⚙️ 사용 방식
템플릿은 서버 측 애플리케이션에서 템플릿 엔진(예: Python의 Jinja2)을 사용해 렌더링되며, 동적 콘텐츠가 포함된 완전한 HTML 페이지를 생성합니다. 주요 기능은 다음과 같습니다:
- 동적 데이터 삽입
- 조건부 콘텐츠 표시
- 데이터 컬렉션 반복 처리
- 기본 템플릿 상속
- 정적 자산과의 통합

## 🔌 템플릿 통합 흐름
```
템플릿 요청 → 데이터 바인딩 → 템플릿 처리 → 자산 포함 → 페이지 생성 → 클라이언트 응답
```

---

이 디렉터리는 SignalCraft의 웹 UI를 서버에서 동적으로 생성하는 핵심 역할을 합니다. 특정 템플릿의 구조나 렌더링 방식이 궁금하시면 더 자세히 설명드릴 수 있어요!
