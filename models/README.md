

# 🧠 모델 디렉터리

이 디렉터리는 SignalCraft 애플리케이션에서 사용되는 데이터 모델 및 모델 관련 유틸리티를 포함하고 있습니다.

## 🧭 개요
모델 디렉터리는 SignalCraft 시스템에서 신호 처리 및 머신러닝 작업에 사용되는 데이터 모델, AI 모델, 다양한 유틸리티를 정의하는 Python 모듈들을 포함합니다.

## 📄 파일 목록
- `__init__.py` - 패키지 초기화 파일
- `__pycache__/` - Python 바이트코드 캐시 디렉터리
- `.gitkeep` - Git에서 디렉터리를 유지하기 위한 자리 표시자 파일
- `advanced_signal_preprocessing.py` - 고급 신호 전처리 알고리즘
- `ai_models.py` - AI 모델 정의 및 구현
- `database.py` - 데이터베이스 모델 정의
- `ensemble_learning.py` - 앙상블 학습 구현
- `model_training_utils.py` - 모델 학습 유틸리티
- `parallel_processor.py` - 모델 병렬 처리 유틸리티
- `refrigerator_diagnosis_cnn.py` - 냉장고 진단용 CNN 모델
- `streaming_processor_optimized.py` - 최적화된 스트리밍 처리기
- `user.py` - 사용자 데이터 모델

## 🔄 모델 아키텍처 흐름
```
원시 오디오 입력 → 신호 전처리 → 특징 추출 → AI 모델 추론 → 분류 → 결과 출력
```

## 🎯 목적
이 디렉터리는 다음을 위한 중심 저장소 역할을 합니다:
- 데이터 모델 정의
- AI 및 머신러닝 모델 아키텍처
- 데이터베이스 스키마 정의
- 모델 학습 유틸리티
- 신호 처리 알고리즘

## 🔑 주요 구성 요소
- **AI 모델**: 오디오 분석을 위한 신경망 아키텍처 포함
- **데이터베이스 모델**: 데이터 저장 구조 정의
- **신호 처리**: 오디오 신호 전처리 알고리즘
- **앙상블 학습**: 여러 모델을 결합하여 예측 성능 향상

## 🧪 모델 파이프라인 흐름
```
데이터 입력 → 전처리 → 특징 엔지니어링 → 모델 학습 → 검증 → 배포 → 추론 → 결과
```

## 📂 모델 분류

### 🎧 신호 처리 모델
```
원시 오디오 → 필터링 → 정규화 → 특징 추출 → 처리된 특징
```

### 🤖 AI/ML 모델
```
처리된 특징 → 신경망 → 분류 → 신뢰도 점수 → 이상 탐지
```

### 🔗 앙상블 모델
```
다중 모델 → 예측 결합 → 가중 결과 → 최종 분류
```

## 🧬 모델 유형
이 디렉터리에는 다음과 같은 모델이 포함됩니다:
- 냉장고/압축기 진단용 CNN 모델
- 앙상블 학습 방식
- 실시간 오디오 처리 모델
- 신호 전처리 및 특징 추출 모델

- 모델 추론을 위한 AI 서비스
- 모델 재학습을 위한 학습 파이프라인
- 모델 업데이트를 위한 배포 서비스
