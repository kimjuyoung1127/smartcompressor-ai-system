# 📤 Uploads 디렉터리

이 디렉터리는 SignalCraft 애플리케이션에서 파일 업로드를 처리하는 역할을 합니다.

## 🧭 개요
Uploads 디렉터리는 사용자 또는 시스템이 SignalCraft에 업로드한 파일을 저장하기 위한 공간입니다. 특히 AI 시스템이 분석하는 오디오 파일 저장에 중점을 둡니다.

## 📁 디렉터리 구조
- `audio/` - 오디오 파일 업로드 전용 하위 디렉터리  
- `.gitkeep` - Git에서 디렉터리를 추적하기 위한 자리 표시자 파일

## 🔄 파일 처리 흐름
```
사용자 업로드 요청 → 파일 유효성 검사 → 바이러스 검사 → 형식 확인 → 저장 → DB 등록 → 처리 큐 등록 → AI 분석 → 결과 생성
```

## 🎯 목적
이 디렉터리는 다음과 같은 파일을 저장하는 역할을 합니다:
- 분석을 위한 사용자 업로드 오디오 파일
- IoT 장치에서 수집된 센서 데이터
- 기타 사용자 또는 시스템이 처리 목적으로 업로드한 파일

## 🧪 업로드 처리 파이프라인
```
파일 업로드 → 유효성 검사 → 파일명 정제 → 저장 → DB 기록 → 분석 트리거 → 결과 처리
```

## 🔐 보안 고려사항
이 디렉터리는 사용자 업로드를 처리하므로 다음과 같은 보안 조치가 필요합니다:
- 악성 파일 업로드 방지를 위한 파일 형식 검증
- 저장 공간 남용 방지를 위한 파일 크기 제한
- 경로 탐색 공격 방지를 위한 파일명 정제
- 추가 보안을 위해 웹 루트 외부에 파일 저장 고려

## 🗑️ 파일 관리
오디오 파일은 크기가 크고 시간이 지나면 누적되므로, 저장 공간 관리를 위해 주기적인 정리 작업이 필요할 수 있습니다.

## 🔌 통합 지점
- AI 서비스: 오디오 분석 수행
- 데이터베이스: 파일 메타데이터 저장
- 알림 서비스: 처리 결과 알림 전송
- 분석 서비스: 업로드 사용량 추적
- 보안 서비스: 파일 검증 및 보호

---

이 디렉터리는 SignalCraft의 데이터 흐름에서 사용자 입력을 받아 AI 분석으로 연결하는 중요한 관문입니다. 업로드 처리 방식이나 보안 설정에 대해 더 알고 싶으시면 도와드릴게요!
