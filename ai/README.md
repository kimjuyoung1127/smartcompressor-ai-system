
# 📁 AI 디렉토리

이 디렉토리는 SignalCraft 오디오 분석 시스템의 **AI 관련 모든 구성 요소**를 포함하고 있습니다.

---

## 🧭 개요

`AI` 디렉토리에는 SignalCraft 시스템의 **오디오 분석 및 이상 감지 기능**을 구현하는 머신러닝 모델, 학습 스크립트, 데이터 처리 유틸리티 등 AI 관련 코드가 포함되어 있습니다.

## 🧱 AI 시스템 아키텍처 흐름

```
원시 오디오 입력
        ↓
전처리 및 특성 추출
        ↓
특성 선택 및 강화
        ↓
모델 추론 (CNN / 앙상블)
        ↓
이상 감지
        ↓
임계값 평가
        ↓
분류 결정
        ↓
결과 출력 및 신뢰도 점수
```


## 🔄 주요 AI 파이프라인 단계

### 📌 1단계: 데이터 전처리
1. 원시 오디오 수집  
2. 노이즈 제거 및 필터링  
3. 특성 추출 (스펙트로그램, MFCC 등)  
4. 데이터 정규화

### 📌 2단계: 모델 학습
1. 데이터셋 준비 및 증강  
2. 모델 아키텍처 선택  
3. 라벨링된 데이터로 학습  
4. 검증 및 하이퍼파라미터 튜닝

### 📌 3단계: 추론 및 이상 감지
1. 실시간 오디오 처리  
2. 실시간 특성 추출  
3. 학습된 모델을 통한 이상 감지  
4. 신뢰도 점수 기반 경고 생성

## ⚙️ 기술 세부사항

AI 구성 요소는 주로 **TensorFlow/Keras**를 사용하여 딥러닝 모델을 구현하며,  
데이터 전처리, 특성 추출, 모델 평가를 위한 다양한 도구들이 함께 사용됩니다.  
이 시스템은 **산업용 압축기의 오디오 신호에서 이상을 감지**하기 위해 CNN과 엔지니어의 도메인 지식을 결합한 구조로 설계되었습니다.

## 🧬 AI 모델 아키텍처

```
입력층 (오디오 스펙트로그램)
        ↓
Conv Block 1 (32 필터) → 배치 정규화 → 드롭아웃
        ↓
Conv Block 2 (64 필터) → 배치 정규화 → 드롭아웃
        ↓
Conv Block 3 (128 필터) → 배치 정규화 → 드롭아웃
        ↓
Conv Block 4 (256 필터) → 글로벌 평균 풀링
        ↓
Dense Layer (512) → 드롭아웃 → Dense Layer (256) → 드롭아웃
        ↓
출력층 (3 클래스: 정상, 누출, 과부하)
```
