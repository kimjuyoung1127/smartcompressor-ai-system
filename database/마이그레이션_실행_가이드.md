## 🚀 마이그레이션 실행 방법

### 방법 1: 마이그레이션 스크립트 사용 (권장)

```bash
# 프로젝트 루트에서 실행
node database/migrate.js
```

이 스크립트는:
- 대기 중인 모든 마이그레이션을 자동으로 실행
- 마이그레이션 상태를 추적
- 실행 이력을 `schema_migrations` 테이블에 저장

### 방법 2: 직접 SQL 파일 실행

```bash
# PostgreSQL에 직접 실행
psql -U postgres -d smartcompressor_ai -f database/migrations/20241104180000_add_core_tables_and_improvements.sql
```

### 방법 3: 전체 스키마 재생성 (개발 환경용)

```bash
# 기존 테이블 삭제 후 전체 스키마 재생성 (주의: 데이터 삭제됨!)
psql -U postgres -d smartcompressor_ai -f database/schema.sql
```

## ⚠️ 주의사항

### 프로덕션 환경
1. **반드시 백업 먼저!**
   ```bash
   pg_dump -U postgres smartcompressor_ai > backup_$(date +%Y%m%d_%H%M%S).sql
   ```

2. **스테이징 환경에서 먼저 테스트**
   - 프로덕션 배포 전 스테이징에서 검증 필수

3. **데이터 타입 변환 주의**
   - `stores.owner_id`: VARCHAR → INTEGER 변환
   - 기존 데이터가 숫자 형식이 아니면 오류 발생 가능

### 개발 환경
- 마이그레이션 실행 전에 기존 데이터 확인
- 필요시 데이터 마이그레이션 스크립트 작성

## 🔍 마이그레이션 상태 확인

### 마이그레이션 상태 조회
```bash
node database/migrate.js --status
```

### 데이터베이스에서 직접 확인
```sql
-- 마이그레이션 이력 확인
SELECT * FROM schema_migrations ORDER BY applied_at DESC;

-- 새로 생성된 테이블 확인
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public' 
  AND table_name IN ('sessions', 'user_store_access', 'sensor_readings', 'anomalies', 'sensor_statistics')
ORDER BY table_name;

-- 외래키 제약조건 확인
SELECT 
    tc.table_name, 
    kcu.column_name, 
    ccu.table_name AS foreign_table_name,
    ccu.column_name AS foreign_column_name 
FROM information_schema.table_constraints AS tc 
JOIN information_schema.key_column_usage AS kcu
    ON tc.constraint_name = kcu.constraint_name
JOIN information_schema.constraint_column_usage AS ccu
    ON ccu.constraint_name = tc.constraint_name
WHERE tc.constraint_type = 'FOREIGN KEY'
ORDER BY tc.table_name;
```

## 🐛 문제 해결

### 에러: "column does not exist"
- 마이그레이션이 순서대로 실행되지 않음
- `schema.sql`을 직접 실행하거나 순서 확인

### 에러: "foreign key constraint violation"
- 기존 데이터에 외래키 위반이 있음
- 데이터 정리 후 다시 실행

### 에러: "cannot cast type"
- 데이터 타입 변환 실패 (예: VARCHAR → INTEGER)
- 데이터 마이그레이션 스크립트 필요
