# 서버에서 마이그레이션 실행 가이드

## 🔍 문제 상황

```
psql: error: connection to server on socket "/var/run/postgresql/.s.PGSQL.5432" failed: FATAL:  role "ubuntu" does not exist
```

**원인**: 환경 변수가 로드되지 않아서 시스템 사용자 `ubuntu`로 접속을 시도했습니다.

## ✅ 해결 방법

### 방법 1: .env 파일을 source로 로드 (권장)

```bash
# 1. 프로젝트 디렉토리로 이동
cd /var/www/smartcompressor

# 2. .env 파일을 source로 로드 (중요!)
source .env

# 3. 환경 변수 확인
echo "DB_HOST: $DB_HOST"
echo "DB_USER: $DB_USER"
echo "DB_NAME: $DB_NAME"
echo "DB_PORT: $DB_PORT"

# 4. 비밀번호 환경 변수 설정
export PGPASSWORD="$DB_PASSWORD"

# 5. 마이그레이션 실행
psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -f database/migrations/20241104180000_add_core_tables_and_improvements.sql

# 6. 결과 확인
psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -c "\dt sessions user_store_access sensor_readings anomalies sensor_statistics"
```

### 방법 2: 직접 환경 변수 설정

```bash
cd /var/www/smartcompressor

# .env 파일에서 직접 읽어서 설정
export DB_HOST=$(grep "^DB_HOST=" .env | cut -d '=' -f2)
export DB_USER=$(grep "^DB_USER=" .env | cut -d '=' -f2)
export DB_NAME=$(grep "^DB_NAME=" .env | cut -d '=' -f2)
export DB_PORT=$(grep "^DB_PORT=" .env | cut -d '=' -f2)
export DB_PASSWORD=$(grep "^DB_PASSWORD=" .env | cut -d '=' -f2)
export PGPASSWORD="$DB_PASSWORD"

# 마이그레이션 실행
psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -f database/migrations/20241104180000_add_core_tables_and_improvements.sql
```

### 방법 3: Node.js 마이그레이션 스크립트 사용

```bash
cd /var/www/smartcompressor

# .env 파일을 로드하고 Node.js 스크립트 실행
export $(grep -v '^#' .env | xargs)
node database/migrate.js
```

### 방법 4: 직접 연결 정보 입력 (RDS 사용 시)

RDS를 사용하는 경우:

```bash
cd /var/www/smartcompressor

# .env 파일에서 실제 값 확인
cat .env | grep DB_

# 직접 값 입력 (예시)
export DB_HOST="your-rds-endpoint.region.rds.amazonaws.com"
export DB_USER="postgres"
export DB_NAME="smartcompressor_ai"

export PGPASSWORD="$DB_PASSWORD"

# 마이그레이션 실행
psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -f database/migrations/20241104180000_add_core_tables_and_improvements.sql
```

## 🔍 .env 파일 확인

먼저 .env 파일의 내용을 확인하세요:

```bash
cd /var/www/smartcompressor

# DB 관련 환경 변수만 확인 (비밀번호는 마스킹)
cat .env | grep -E '^DB_' | sed 's/\(PASSWORD=\).*/\1***/'
```

## 📋 실행 후 확인

마이그레이션 실행 후 다음 명령어로 확인:

```bash
# 1. 새로 생성된 테이블 확인
psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -c "\dt sessions user_store_access sensor_readings anomalies sensor_statistics"

# 2. 외래키 제약조건 확인
psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -c "
SELECT 
    tc.table_name, 
    kcu.column_name, 
    ccu.table_name AS foreign_table_name
FROM information_schema.table_constraints AS tc 
JOIN information_schema.key_column_usage AS kcu
    ON tc.constraint_name = kcu.constraint_name
JOIN information_schema.constraint_column_usage AS ccu
    ON ccu.constraint_name = tc.constraint_name
WHERE tc.constraint_type = 'FOREIGN KEY'
    AND tc.table_name IN ('sessions', 'user_store_access', 'sensor_readings', 'anomalies')
ORDER BY tc.table_name;
"

# 3. 인덱스 확인
psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -c "
SELECT 
    tablename,
    indexname
FROM pg_indexes
WHERE tablename IN ('sessions', 'user_store_access', 'sensor_readings', 'anomalies', 'sensor_statistics')
ORDER BY tablename, indexname;
"
```

## ⚠️ 주의사항

1. **환경 변수 로드 필수**: `.env` 파일을 `source`로 로드하거나 직접 `export`해야 합니다.
2. **비밀번호 보안**: 실행 후 `unset PGPASSWORD`로 비밀번호 환경 변수 제거
3. **백업**: 프로덕션 환경에서는 마이그레이션 전 백업 필수

## 💡 빠른 실행 명령어 (한 줄)

```bash
cd /var/www/smartcompressor && source .env && export PGPASSWORD="$DB_PASSWORD" && psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -f database/migrations/20241104180000_add_core_tables_and_improvements.sql && unset PGPASSWORD
```
