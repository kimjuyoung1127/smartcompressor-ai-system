# 스키마 개선 완료 보고서

## 📅 개선 일자
2024-11-04

## ✅ 완료된 개선 사항

### 1단계: 핵심 테이블 추가 ✅

다음 테이블들을 추가했습니다:

#### 인증 및 세션 관리
- **`sessions`** - 사용자 세션 관리
  - session_id, user_id, expires_at 등
  - 인덱스: session_id, user_id, expires_at

#### 권한 관리
- **`user_store_access`** - 사용자 매장 접근 권한
  - user_id, store_id 복합 기본키
  - permissions JSONB 필드로 유연한 권한 관리
  - 인덱스: user_id, store_id

#### 센서 데이터
- **`sensor_readings`** - 센서 데이터 수집 (시계열)
  - temperature, vibration_x/y/z, power_consumption 등
  - device_id 외래키 관계
  - 인덱스: device_id, timestamp, device_id+timestamp

- **`anomalies`** - 이상 감지 결과
  - anomaly_type, severity, confidence
  - is_resolved 플래그로 해결 상태 관리
  - 인덱스: device_id, timestamp, type, severity, resolved

- **`sensor_statistics`** - 센서 통계 집계
  - 시간별 집계 데이터 (device_id, date, hour)
  - UNIQUE 제약조건으로 중복 방지
  - 인덱스: device_id, date, device_id+date

### 2단계: 데이터 타입 통일 ✅

#### stores 테이블 개선
- `owner_id`를 VARCHAR(50) → INTEGER로 변경
- `users(id)` 외래키 관계 추가
- `updated_at` 컬럼 추가

#### devices 테이블 개선
- `device_name`, `firmware_version`, `hardware_version` 추가
- `last_seen`, `status` 필드 추가
- `updated_at` 컬럼 추가

### 3단계: 외래키 관계 정의 ✅

#### audio_files 테이블
- `store_id`: INTEGER → VARCHAR(50) 변경
- `device_id`: INTEGER → VARCHAR(50) 변경
- 외래키 제약조건 추가:
  - `fk_audio_files_store` → stores(id)
  - `fk_audio_files_device` → devices(id)

#### monitoring_data 테이블
- `store_id`: INTEGER → VARCHAR(50) 변경
- `device_id`: INTEGER → VARCHAR(50) 변경
- 외래키 제약조건 추가:
  - `fk_monitoring_data_store` → stores(id)
  - `fk_monitoring_data_device` → devices(id)

### 4단계: 표준 필드 추가 ✅

#### 소프트 삭제 지원
다음 테이블에 `deleted_at` 컬럼 추가:
- users
- stores
- devices
- labels
- experts
- audio_files
- sessions

#### 자동 업데이트 트리거
- `stores` 테이블: updated_at 자동 업데이트
- `devices` 테이블: updated_at 자동 업데이트
