# 서버 동기화 가이드

## ✅ 현재 상태

### 완료된 작업
- ✅ 로컬에 스키마 파일 생성 완료
- ✅ GitHub에 푸시 완료 (`pr4-resolve` 브랜치)

### 서버 동기화 필요
서버에도 스키마 파일을 동기화해야 합니다.

## 🚀 서버 동기화 방법

### 방법 1: GitHub Actions 자동 배포 (권장)

**조건**: `main` 브랜치에 머지되면 자동 배포됩니다.

```bash
# 1. main 브랜치로 전환
git checkout main

# 2. pr4-resolve 브랜치를 main에 머지
git merge pr4-resolve

# 3. main 브랜치에 푸시
git push origin main
```

→ GitHub Actions가 자동으로 서버에 배포합니다.

### 방법 2: 수동 배포 (지금 바로 적용)

서버에 직접 SSH 접속하여 최신 코드를 가져옵니다:

```bash
# 서버에 SSH 접속
ssh ubuntu@3.39.124.0

# 프로젝트 디렉토리로 이동
cd /var/www/smartcompressor

# pr4-resolve 브랜치로 전환
git fetch origin
git checkout pr4-resolve
git pull origin pr4-resolve

# 또는 main 브랜치에서 최신 코드 가져오기
# git checkout main
# git pull origin main
```

### 방법 3: 배포 스크립트 사용

```bash
# 로컬에서 실행
bash scripts/deploy-ec2-pm2.sh
```

또는

```powershell
# PowerShell에서 실행
.\scripts\deploy-ec2-pm2.ps1
```

## 📋 배포 후 확인 사항

### 1. 스키마 파일 확인
```bash
# 서버에서 확인
ls -la /var/www/smartcompressor/database/
```

다음 파일들이 있어야 합니다:
- `schema.sql`
- `migrate.js`
- `README.md`
- `SCHEMA_GUIDE.md`
- `migrations/` 폴더

### 2. 데이터베이스 서비스 확인
```bash
# 서버에서 확인
cat /var/www/smartcompressor/services/database_service.js | grep schema.sql
```

`database/schema.sql`을 읽는 코드가 있어야 합니다.

### 3. 서버 재시작
```bash
# PM2로 관리되는 경우
pm2 restart all

# 또는 직접 실행하는 경우
# 서버 재시작 필요
```

## ⚠️ 주의사항

1. **데이터베이스 마이그레이션**
   - 서버의 데이터베이스에 스키마를 적용하려면:
   ```bash
   node database/migrate.js
   ```
   또는
   ```bash
   psql -U postgres -d smartcompressor_ai -f database/schema.sql
   ```

2. **백업**
   - 프로덕션 데이터베이스 변경 전 항상 백업하세요!

3. **테스트**
   - 스테이징 환경에서 먼저 테스트하는 것을 권장합니다.
