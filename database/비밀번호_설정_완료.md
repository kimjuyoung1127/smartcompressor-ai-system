```bash

  --host=localhost \
  --port=5432 \
  --username=postgres \
  --dbname=smartcompressor_ai
```

또는 더 간단하게:

```bash
export PGPASSWORD='signalcraft6898'
psql -h localhost -U postgres -d smartcompressor_ai
```

- 만약 애플리케이션이 연결에 실패한다면, `.env` 파일에 `DB_PASSWORD=signalcraft6898`을 추가하거나 PM2 환경 변수를 업데이트해야 할 수 있습니다.
