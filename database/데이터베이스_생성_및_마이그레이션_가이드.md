# 데이터베이스 생성 및 마이그레이션 가이드

## 🔍 현재 상황
- `smartcompressor_ai` 데이터베이스가 존재하지 않음
- 데이터베이스를 먼저 생성한 후 마이그레이션 실행 필요

## ✅ 해결 방법

### 방법 1: 데이터베이스 생성 후 전체 스키마 적용 (권장)

```bash
cd /var/www/smartcompressor

# 1. 데이터베이스 생성
sudo -u postgres psql -c "CREATE DATABASE smartcompressor_ai;"

# 2. 전체 스키마 적용 (초기 설정)
sudo -u postgres psql -d smartcompressor_ai -f database/schema.sql

# 3. 마이그레이션 실행 (추가 테이블)
sudo -u postgres psql -d smartcompressor_ai -f database/migrations/20241104180000_add_core_tables_and_improvements.sql
```

### 방법 2: 데이터베이스 생성 후 마이그레이션만 실행

스키마 파일에 이미 테이블이 포함되어 있으므로, 마이그레이션만 실행해도 됩니다:

```bash
cd /var/www/smartcompressor

# 1. 데이터베이스 생성
sudo -u postgres psql -c "CREATE DATABASE smartcompressor_ai;"

# 2. 마이그레이션 실행 (스키마 파일이 자동으로 테이블 생성)
sudo -u postgres psql -d smartcompressor_ai -f database/migrations/20241104180000_add_core_tables_and_improvements.sql
```

### 방법 3: 단계별 실행

```bash
cd /var/www/smartcompressor

# 1. 데이터베이스 생성
sudo -u postgres psql << EOF
CREATE DATABASE smartcompressor_ai;
\q
EOF

# 2. 데이터베이스 확인
sudo -u postgres psql -l | grep smartcompressor

# 3. 스키마 적용
sudo -u postgres psql -d smartcompressor_ai -f database/schema.sql

# 4. 마이그레이션 적용
sudo -u postgres psql -d smartcompressor_ai -f database/migrations/20241104180000_add_core_tables_and_improvements.sql
```

## 🎯 추천 실행 순서

### 1단계: 데이터베이스 생성

```bash
sudo -u postgres psql -c "CREATE DATABASE smartcompressor_ai;"
```

### 2단계: 전체 스키마 적용

```bash
cd /var/www/smartcompressor
sudo -u postgres psql -d smartcompressor_ai -f database/schema.sql
```

이것만으로도 충분합니다! `schema.sql`에 모든 테이블이 포함되어 있으므로, 마이그레이션은 이미 적용된 스키마를 업데이트하는 용도입니다.

### 3단계: 마이그레이션 실행 (선택사항)

```bash
sudo -u postgres psql -d smartcompressor_ai -f database/migrations/20241104180000_add_core_tables_and_improvements.sql
```

## 📋 실행 후 확인

```bash
# 1. 데이터베이스 목록 확인
sudo -u postgres psql -l | grep smartcompressor

# 2. 생성된 테이블 확인
sudo -u postgres psql -d smartcompressor_ai -c "\dt"

# 3. 새로 추가된 테이블 확인
sudo -u postgres psql -d smartcompressor_ai -c "\dt sessions user_store_access sensor_readings anomalies sensor_statistics"

# 4. 외래키 확인
sudo -u postgres psql -d smartcompressor_ai -c "
SELECT 
    tc.table_name, 
    kcu.column_name, 
    ccu.table_name AS foreign_table_name
FROM information_schema.table_constraints AS tc 
JOIN information_schema.key_column_usage AS kcu
    ON tc.constraint_name = kcu.constraint_name
JOIN information_schema.constraint_column_usage AS ccu
    ON ccu.constraint_name = tc.constraint_name
WHERE tc.constraint_type = 'FOREIGN KEY'
ORDER BY tc.table_name;
"
```

## ⚠️ 주의사항

1. **기존 데이터**: 데이터베이스가 새로 생성되므로 기존 데이터는 없습니다.
2. **애플리케이션 연결**: 애플리케이션이 이 데이터베이스에 연결하도록 설정되어 있는지 확인하세요.
3. **권한**: 필요시 사용자 권한 설정:
   ```sql
   GRANT ALL PRIVILEGES ON DATABASE smartcompressor_ai TO postgres;
   ```
