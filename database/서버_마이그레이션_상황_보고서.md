## 🔧 해결 방법

### 방법 1: 서버에서 직접 실행 (권장)

서버에 SSH 접속 후:

```bash
# 1. 서버 접속
ssh -i ~/.ssh/signalcraft-new.pem ubuntu@3.39.124.0

# 2. 프로젝트 디렉토리로 이동
cd /var/www/smartcompressor

# 3. .env 파일 확인 (DB 연결 정보 확인)
cat .env | grep DB_

# 4. 환경 변수 로드 후 마이그레이션 실행
source .env
export PGPASSWORD="$DB_PASSWORD"
psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -f database/migrations/20241104180000_add_core_tables_and_improvements.sql

# 5. 결과 확인
psql -h "$DB_HOST" -U "$DB_USER" -d "$DB_NAME" -c "\dt sessions user_store_access sensor_readings anomalies sensor_statistics"
```

### 방법 2: Node.js 스크립트 사용

서버에서 실제로 사용하는 DB 연결 정보로 실행:

```bash
cd /var/www/smartcompressor

# .env 파일의 환경 변수를 Node.js 프로세스에 로드
export $(grep -v '^#' .env | xargs)

# 마이그레이션 실행
node database/migrate.js
```

### 방법 3: PM2를 통해 실행 중인 프로세스의 환경 변수 확인

```bash
# PM2 환경 변수 확인
pm2 env 0

# 또는 PM2를 통해 환경 변수 설정 후 실행
pm2 restart all --update-env
```
