# 샘플링 및 저장 방식 명확화

## 🔍 질문에 대한 답변

### Q1: 샘플링 간격과 파일 용량의 관계

**답변: 네, 한 개 파일의 용량은 동일합니다. 하지만 수집 횟수가 다릅니다.**

#### 핵심 개념

**샘플링 방식**:
- 전체 녹음본을 올리는 것이 **아닙니다**
- **5초 오디오 샘플**만 주기적으로 수집합니다
- 샘플링 간격 = 수집 주기 (60초, 5분 등)

#### 파일 용량 계산

**1개 파일 (5초 오디오)**:
```
16,000 samples/sec × 2 bytes × 5 sec = 160 KB/파일
```

**이것은 항상 동일합니다!**

#### 샘플링 간격별 비교

| 간격 | 수집 횟수/일 | 1개 파일 용량 | 총 용량/일 | 총 용량/월 |
|------|------------|-------------|-----------|----------|
| 60초 | 1,440개 | 160 KB | 230.4 MB | 6.9 GB |
| 5분 | 288개 | 160 KB | 46.1 MB | 1.38 GB |
| 10분 | 144개 | 160 KB | 23.0 MB | 0.69 GB |

**핵심**: 
- ✅ 한 개 파일 용량은 동일 (160 KB)
- ✅ 수집 횟수가 다름 → 총 용량이 다름
- ✅ 간격을 늘리면 → 수집 횟수 감소 → 총 용량 감소

### Q2: 샘플링이 전체 녹음본을 올리는 게 아닌가?

**답변: 아니요. 전체 녹음본이 아니라 5초 샘플만 수집합니다.**

#### 현재 시스템 동작 방식

```
ESP32 센서
    ↓
5초 오디오 샘플 수집
    ↓
60초마다 서버로 전송 (샘플링 간격)
    ↓
서버에서 AI 분석
    ↓
결과 저장
```

**예시**:
- 00:00:00 - 5초 샘플 수집 → 전송
- 00:01:00 - 5초 샘플 수집 → 전송
- 00:02:00 - 5초 샘플 수집 → 전송
- ...

**전체 녹음이 아닙니다!** 5초 샘플만 주기적으로 수집합니다.

---

### Q3: 로컬에 저장하는 방법은 저장 장치를 로컬에 설치해야 하는가?

**답변: 아니요. EC2 서버의 디스크(EBS)에 저장되므로 별도 저장 장치 설치가 필요 없습니다.**

#### 로컬 저장의 의미

**"로컬" = EC2 서버의 디스크 (EBS)**

```
센서 → ESP32 → EC2 서버
              ↓
         EBS 디스크 (로컬)
              ↓
         SQLite 파일 저장
```

**특징**:
- ✅ 별도 저장 장치 설치 불필요
- ✅ EC2 서버의 디스크에 자동 저장
- ✅ 인터넷 연결 없이도 작동 (오프라인 가능)
- ✅ AWS EBS 스토리지 비용만 발생

**비용**:
- EBS 스토리지: $0.08/GB/월
- 예: 13.8 GB → $1.10/월

### 저장 전략

#### 1. 이상 감지 시에만 저장
```python
if is_anomaly:
    # 오디오 파일 저장 (MP3 압축)
```

#### 2. 저장 내용
- ✅ 오디오 파일 (MP3 압축, 이상만)

#### 3. 정상 데이터 처리

- ✅ 통계 요약만 저장 (하루 1-2회)

## 📊 예상 비용 (하이브리드 저장)

### 가정
- 센서 2개
- 샘플링 간격: 5분 (288 샘플/일)
- 이상 발생률: 5% (14.4개/일)
- 오디오 파일: MP3 압축 (약 20 KB/파일)

### 계산
```
일일 이상 샘플: 14.4개
오디오 파일: 14.4 × 20 KB = 288 KB/일
분석 결과: 14.4 × 2 KB = 28.8 KB/일
특징 데이터: 14.4 × 1 KB = 14.4 KB/일
─────────────────────────────
총 용량: 331.2 KB/일
월간 용량: 9.9 MB/월
```

### 비용
```
EBS 스토리지: 9.9 MB × $0.08/GB = $0.0008/월
EC2: $7.49/월 (프리티어 무료 가능)
─────────────────────────────
총계: $0.0008-7.50/월
```

**거의 무료!** 🎉
