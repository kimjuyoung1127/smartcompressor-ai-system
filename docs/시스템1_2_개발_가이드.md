# 시스템 1 & 2 개발 가이드

## 개요

로드맵 2단계 핵심 투자 시스템 개발 완료:
- **시스템 1**: 고급 스펙트로그램 라벨링 툴 (좌표 기반 영역 선택)
- **시스템 2**: 데이터 웨어하우스 서비스 (대규모 센서 데이터 관리)

---

## 시스템 1: 고급 스펙트로그램 라벨링 툴

### 목적
'전문가의 직감'을 'AI가 학습 가능한 좌표'로 변환하는 도구

### 위치
`ai/advanced_labeling_tool.py`

### 실행 방법

```bash
# Streamlit으로 실행
streamlit run ai/advanced_labeling_tool.py

# 또는 특정 디렉토리 지정
streamlit run ai/advanced_labeling_tool.py -- --input-dir data/spectrograms
```

### 주요 기능

1. **영역 선택 도구**
   - X, Y 좌표와 너비/높이를 입력하여 스펙트로그램의 특정 영역 선택
   - 여러 영역 동시 선택 가능

2. **좌표 데이터 저장**
   - 선택한 영역의 좌표를 JSON 형식으로 저장
   - `annotations/` 폴더에 저장됨
   - AI 모델 학습 시 활용 가능

3. **라벨링 저장**
   - 전체 이미지 레벨 라벨 (정상, 냉매 누설, 과부하 등)
   - 영역별 라벨 (다중 라벨 지원)

### 사용 예시

```python
# Python에서 직접 사용
from ai.advanced_labeling_tool import AdvancedLabelingTool

tool = AdvancedLabelingTool()
tool.setup_directories()
tool.load_images("data/spectrograms")
# Streamlit 인터페이스 실행
tool.run_labeling_interface("data/spectrograms")
```

## 시스템 2: 데이터 웨어하우스 서비스

### 목적
1,000개 센서의 데이터를 '폴더'가 아닌 'DB'로 관리, 분석, 통계

### 위치
`services/data_warehouse_service.py`

### 초기화

```python
from services.data_warehouse_service import DataWarehouseService

# SQLite 사용 (기본)
warehouse = DataWarehouseService()

# PostgreSQL 사용
warehouse = DataWarehouseService({
    'type': 'postgresql',
    'host': 'localhost',
    'port': '5432',
    'database': 'signalcraft_warehouse',
    'user': 'signalcraft',
    'password': 'your_password'
})
```

### 주요 기능

#### 1. 센서 데이터 저장

```python
from datetime import datetime

warehouse.store_sensor_data(
    device_id="device_001",
    timestamp=datetime.now(),
    audio_level=75.5,
    audio_spectrogram_path="data/spectrograms/spectrogram_001.png",
    temperature=25.3,
    vibration_x=0.1,
    vibration_y=0.2,
    vibration_z=0.15,
    power_consumption=1200.0,
    metadata={"location": "부산청산바다", "model": "A-123"}
)
```

#### 2. 데이터 조회

```python
from datetime import datetime, timedelta

start_date = datetime.now() - timedelta(days=30)
end_date = datetime.now()

df = warehouse.get_sensor_data_range(
    device_id="device_001",
    start_date=start_date,
    end_date=end_date
)

print(df.head())
```

#### 3. 통계 집계

```python
from datetime import datetime

stats = warehouse.aggregate_statistics(
    device_id="device_001",
    date=datetime.now().date(),
    hour=12  # 특정 시간대 (선택적)
)

print(stats)
# {
#   'audio': {'avg': 75.5, 'max': 85.0, 'min': 65.0, 'std': 5.2, 'count': 100},
#   'temperature': {'avg': 25.3, 'max': 28.0, 'min': 22.0, 'std': 1.5, 'count': 100},
#   ...
# }
```

### 데이터베이스 스키마

#### sensor_data_warehouse
- 시계열 센서 데이터 저장
- 인덱스: device_id, timestamp

#### sensor_statistics_aggregated
- 일별/시간별 집계 통계
- UNIQUE: device_id, date, hour, sensor_type

#### correlation_analysis
- 상관관계 분석 결과 저장
- 선행 지표 시간, 예측 정확도 등

#### labeled_spectrograms
- 라벨링된 스펙트로그램 메타데이터
- 시스템 1과 연계

## 상관관계 분석 서비스

### 목적
소리 데이터가 온도/진동보다 얼마나 빠르게 이상 징후를 감지하는지 분석

### 위치
`services/correlation_analysis_service.py`

### 사용 예시

```python
from services.correlation_analysis_service import CorrelationAnalysisService
from services.data_warehouse_service import DataWarehouseService
from datetime import datetime, timedelta

warehouse = DataWarehouseService()
correlation = CorrelationAnalysisService(warehouse)

# 실제 고장 이벤트 정의
failure_events = [
    {
        'timestamp': datetime(2024, 1, 15, 14, 30),
        'type': 'leak',
        'description': '냉매 누설'
    }
]

# 분석 수행
start_date = datetime(2024, 1, 1)
end_date = datetime(2024, 1, 31)

result = correlation.analyze_lead_time(
    device_id="device_001",
    start_date=start_date,
    end_date=end_date,
    failure_events=failure_events
)

print(f"소리 센서 평균 선행 일수: {result['audio_sensor']['avg_lead_days']}일")
print(f"정확도: {result['audio_sensor']['accuracy']}%")
```

## 리포트 생성 서비스

### 목적
통계적 증명 결과를 산업 리포트로 자동 생성

### 위치
`services/report_generator_service.py`

### 사용 예시

```python
from services.report_generator_service import ReportGeneratorService
from services.correlation_analysis_service import CorrelationAnalysisService
from services.data_warehouse_service import DataWarehouseService
from datetime import datetime, timedelta

warehouse = DataWarehouseService()
correlation = CorrelationAnalysisService(warehouse)
generator = ReportGeneratorService(warehouse, correlation)

# 여러 디바이스 분석
device_ids = ["device_001", "device_002", "device_003"]

failure_events_by_device = {
    "device_001": [
        {'timestamp': datetime(2024, 1, 15, 14, 30), 'type': 'leak'}
    ],
    "device_002": [
        {'timestamp': datetime(2024, 1, 20, 10, 15), 'type': 'overload'}
    ]
}

start_date = datetime(2024, 1, 1)
end_date = datetime(2024, 1, 31)

# 리포트 생성
report_result = generator.generate_industry_report(
    device_ids=device_ids,
    start_date=start_date,
    end_date=end_date,
    failure_events_by_device=failure_events_by_device,
    report_title="시그널크래프트 산업 리포트 2024 Q1"
)

print(f"리포트 JSON: {report_result['files']['json']}")
print(f"리포트 Markdown: {report_result['files']['markdown']}")
```

### 생성되는 리포트 형식

- **JSON**: 구조화된 데이터
- **Markdown**: 읽기 쉬운 문서 형식

리포트에는 다음이 포함됩니다:
- 경영진 요약
- 주요 발견사항
- 상세 분석 결과
- 권장사항
