# 테스트 실행 빠른 가이드

## ⚡ 빠른 시작

### PowerShell에서 WSL로 전환

PowerShell에서 다음 명령어로 WSL로 전환하세요:

```powershell
wsl
```

그 다음 WSL 터미널에서:

```bash
cd /root/smartcompressor-ai-system

# pytest 설치 (처음 한 번만)
pip install pytest pytest-cov pytest-asyncio

# 테스트 실행
pytest tests/
```

## 🔧 상세 가이드

### 1단계: WSL 터미널 열기

**방법 1**: PowerShell에서
```powershell
wsl
```

**방법 2**: Windows 시작 메뉴에서 "Ubuntu" 검색

### 2단계: 프로젝트 디렉토리로 이동

```bash
cd /root/smartcompressor-ai-system
```

### 3단계: pytest 설치

```bash
# 가상 환경이 있다면 활성화
source venv/bin/activate

# pytest 설치
pip install pytest pytest-cov pytest-asyncio

# 또는 requirements.txt에서 설치
pip install -r requirements.txt
```

### 4단계: 테스트 실행

```bash
# 모든 테스트 실행
pytest tests/

# 상세 출력
pytest tests/ -v

# 커버리지 포함
pytest tests/ --cov=services/anomaly_detection_modules --cov-report=html
```

## 🐛 문제 해결

### 문제 1: "pytest: command not found"

**해결 방법:**
```bash
pip install pytest pytest-cov pytest-asyncio
```

### 문제 2: "ModuleNotFoundError"

**해결 방법:**
```bash
# 프로젝트 루트에서 실행 확인
pwd  # /root/smartcompressor-ai-system 확인

# PYTHONPATH 설정
export PYTHONPATH=/root/smartcompressor-ai-system:$PYTHONPATH
```

### 문제 3: "Permission denied"

**해결 방법:**
```bash
# 스크립트에 실행 권한 부여
chmod +x scripts/run_tests.sh
```

## 💡 팁

1. **WSL 사용**: PowerShell에서 직접 실행하지 말고 WSL 터미널을 사용하세요.

2. **가상 환경**: 가상 환경을 사용하면 패키지 충돌을 방지할 수 있습니다.

3. **커버리지 리포트**: `htmlcov/index.html` 파일을 브라우저에서 열어 상세 커버리지를 확인하세요.
