# 24시간 자동 모니터링 중단 가이드

## 📋 개요

주영님이 개발한 24시간 자동 모니터링 기능을 중단하는 방법입니다.
main 브랜치 머지 전에 모니터링 기능을 비활성화해야 합니다.

---

## 🔴 24시간 모니터링 시작 지점

### 1. `app.py` (서버 시작 시 자동 실행)
```python
# Line 200 근처
sensor_monitoring_service.start_monitoring()
```

### 2. `routes/monitoring_routes.py` (API 엔드포인트)
```python
# API로 모니터링 시작 가능
@monitoring_bp.route('/start', methods=['POST'])
def start_monitoring():
    monitoring_service.start_monitoring()
```

### 방법 2: `routes/monitoring_routes.py`에서 API 비활성화

**파일**: `routes/monitoring_routes.py`

**수정 전**:
```python
@monitoring_bp.route('/start', methods=['POST'])
def start_monitoring():
    try:
        monitoring_service.start_monitoring()
        return jsonify({'status': 'success', 'message': '모니터링 시작'})
    except Exception as e:
        return jsonify({'status': 'error', 'message': str(e)}), 500
```

**수정 후**:
```python
@monitoring_bp.route('/start', methods=['POST'])
def start_monitoring():
    # 24시간 모니터링 기능 중단 (주영님 요청)
    return jsonify({
        'status': 'disabled',
        'message': '24시간 모니터링 기능이 중단되었습니다.'
    }), 503  # Service Unavailable
```

### 방법 3: `services/realtime_monitoring.py`에서 기본값 변경

**파일**: `services/realtime_monitoring.py`

**수정 전**:
```python
def start_monitoring(self):
    if self.is_running:
        logger.warning("모니터링이 이미 실행 중입니다.")
        return

    self.is_running = True
    self.monitoring_thread = threading.Thread(target=self._monitoring_loop)
    self.monitoring_thread.daemon = True
    self.monitoring_thread.start()

    logger.info("24시간 모니터링 서비스 시작")
```

**수정 후**:
```python
def start_monitoring(self):
    # 24시간 모니터링 기능 중단 (주영님 요청)
    logger.warning("24시간 모니터링 기능이 중단되었습니다.")
    return
    
    # 아래 코드는 실행되지 않음
    if self.is_running:
        logger.warning("모니터링이 이미 실행 중입니다.")
        return

    self.is_running = True
    self.monitoring_thread = threading.Thread(target=self._monitoring_loop)
    self.monitoring_thread.daemon = True
    self.monitoring_thread.start()

    logger.info("24시간 모니터링 서비스 시작")
```

## 🔍 현재 실행 중인 모니터링 확인

### 1. 프로세스 확인
```bash
# WSL에서 실행
ps aux | grep monitoring
ps aux | grep python | grep monitoring
```

### 2. 데이터베이스 확인
```bash
# 모니터링 로그 확인
ls -lh data/monitoring.db
sqlite3 data/monitoring.db "SELECT COUNT(*) FROM monitoring_logs WHERE timestamp > datetime('now', '-1 hour');"
```

### 3. 로그 확인
```bash
# 서버 로그에서 모니터링 관련 메시지 확인
grep -i "monitoring" logs/*.log
```
