# 테스트 오류 해결 가이드

## 현재 오류

### 문제: `No module named 'seaborn'`

**원인**: 다른 서비스 파일들(`advanced_analytics_service.py`, `automated_reporting_service.py` 등)에서 seaborn을 import하고 있어서, 간접적으로 필요함

---

## 해결 방법

### 방법 1: seaborn 설치 (권장)

**WSL 터미널에서 실행:**

```bash
# 가상환경 활성화
source venv/bin/activate

# seaborn 설치
pip install seaborn
```

### 방법 2: requirements.txt 확인

```bash
# requirements.txt에 seaborn이 있는지 확인
grep seaborn requirements.txt

# 없으면 추가 후 설치
pip install -r requirements.txt
```

---

## 테스트 재실행

설치 후 다시 테스트:

```bash
python scripts/test_smart_detection_system.py
```

---

## 추가 발견된 문제

### 1. MIMII 모델 특징 개수 불일치

**오류**: `X has 10 features, but StandardScaler is expecting 44 features`

**원인**: MIMII 모델은 44개 특징을 기대하지만, 우리가 10개만 추출

**해결**: 
- MIMII 모델의 실제 특징 추출 방식 확인 필요
- `services/ai_service.py`의 `_extract_comprehensive_features` 사용

### 2. 처리 시간이 느림

**발견**: 27.48초 (27448ms) - 너무 느림

**원인**: TensorFlow 초기화 시간

**해결**: 
- 첫 실행 시 느림 (정상)
- 이후 실행은 더 빠름
