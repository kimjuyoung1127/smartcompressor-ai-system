## 💡 권장 알고리즘: **실시간 스펙트럼 이상 점수 (Real-time Spectral Anomaly Score)**

### 핵심 개념

**정상 기준선과의 즉시 비교**:
- 정상 상태의 스펙트럼 패턴을 기준선으로 설정
- 실시간으로 들어오는 소리를 스펙트럼 분석
- 기준선과의 차이를 즉시 점수화
- 점수가 임계값을 넘으면 "고장 신호 감지!"

## 🔬 알고리즘 상세

### 1. 정상 기준선 설정 (초기 1-2일)

```python
def establish_baseline(audio_samples: List[np.ndarray]) -> Dict:
    """
    정상 상태 기준선 설정
    초기 1-2일 동안 정상 소리 수집하여 기준선 생성
    """
    baseline_features = {
        'spectral_centroid_mean': 0.0,
        'spectral_centroid_std': 0.0,
        'rms_energy_mean': 0.0,
        'rms_energy_std': 0.0,
        'high_freq_energy_ratio_mean': 0.0,
        'high_freq_energy_ratio_std': 0.0,
        'zcr_mean': 0.0,
        'zcr_std': 0.0,
        'spectral_pattern': None  # 정상 스펙트럼 패턴
    }
    
    # 모든 샘플에서 특징 추출
    all_features = []
    for audio in audio_samples:
        features = extract_features(audio)
        all_features.append(features)
    
    # 통계 계산
    baseline_features['spectral_centroid_mean'] = np.mean([f['spectral_centroid'] for f in all_features])
    baseline_features['spectral_centroid_std'] = np.std([f['spectral_centroid'] for f in all_features])
    baseline_features['rms_energy_mean'] = np.mean([f['rms_energy'] for f in all_features])
    baseline_features['rms_energy_std'] = np.std([f['rms_energy'] for f in all_features])
    # ... 기타 특징들
    
    return baseline_features
```

**장점**:
- ✅ 초기 1-2일만 수집하면 됨
- ✅ 모든 압축기에 공통 적용 가능
- ✅ 환경에 자동 적응

### 2. 실시간 이상 점수 계산

```python
def calculate_anomaly_score(audio_data: np.ndarray, baseline: Dict) -> Dict:
    """
    실시간 이상 점수 계산
    즉시 "고장 신호" 여부를 판단
    """
    # 1. 특징 추출 (즉시)
    features = extract_features(audio_data)
    
    # 2. 각 특징별 이상 점수 계산
    anomaly_scores = {}
    
    # 스펙트럼 중심 이상 점수
    centroid_z_score = abs(
        (features['spectral_centroid'] - baseline['spectral_centroid_mean']) 
        / (baseline['spectral_centroid_std'] + 1e-6)
    )
    anomaly_scores['spectral_centroid'] = min(1.0, centroid_z_score / 3.0)
    
    # RMS 에너지 이상 점수
    energy_z_score = abs(
        (features['rms_energy'] - baseline['rms_energy_mean'])
        / (baseline['rms_energy_std'] + 1e-6)
    )
    anomaly_scores['rms_energy'] = min(1.0, energy_z_score / 3.0)
    
    # 고주파 에너지 비율 이상 점수 (베어링 마모 등)
    high_freq_z_score = abs(
        (features['high_freq_energy_ratio'] - baseline['high_freq_energy_ratio_mean'])
        / (baseline['high_freq_energy_ratio_std'] + 1e-6)
    )
    anomaly_scores['high_freq_energy'] = min(1.0, high_freq_z_score / 3.0)
    
    # Zero Crossing Rate 이상 점수 (날카로운 소음)
    zcr_z_score = abs(
        (features['zcr'] - baseline['zcr_mean'])
        / (baseline['zcr_std'] + 1e-6)
    )
    anomaly_scores['zcr'] = min(1.0, zcr_z_score / 3.0)
    
    # 3. 종합 이상 점수 (가중 평균)
    total_score = (
        0.3 * anomaly_scores['spectral_centroid'] +
        0.3 * anomaly_scores['rms_energy'] +
        0.25 * anomaly_scores['high_freq_energy'] +
        0.15 * anomaly_scores['zcr']
    )
    
    # 4. 고장 신호 판단
    is_failure_signal = total_score > 0.7  # 임계값 70%
    
    return {
        'anomaly_score': total_score,
        'is_failure_signal': is_failure_signal,
        'individual_scores': anomaly_scores,
        'confidence': min(1.0, total_score * 1.2),  # 신뢰도
        'failure_type': classify_failure_type(anomaly_scores),
        'message': '고장 신호 감지!' if is_failure_signal else '정상'
    }
```

**장점**:
- ✅ 즉시 계산 가능 (실시간)
- ✅ 모든 압축기에 공통 적용
- ✅ 명확한 점수 (0-100%)

### 3. 고장 유형 분류

```python
def classify_failure_type(anomaly_scores: Dict) -> str:
    """
    이상 점수 기반 고장 유형 분류
    """
    # 베어링 마모: 고주파 에너지 증가
    if anomaly_scores['high_freq_energy'] > 0.7:
        return 'bearing_wear'
    
    # 파열음: RMS 에너지 급증
    if anomaly_scores['rms_energy'] > 0.8:
        return 'burst_sound'
    
    # 언밸런스: 스펙트럼 중심 변화
    if anomaly_scores['spectral_centroid'] > 0.7:
        return 'unbalance'
    
    # 마찰음: ZCR 증가
    if anomaly_scores['zcr'] > 0.7:
        return 'friction'
    
    return 'general_anomaly'
```
