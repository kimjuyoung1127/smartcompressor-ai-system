### 전략 1: 데시벨 기반 1차 필터링 (빠른 판단)

```python
def first_stage_filter(decibel_level: float) -> str:
    """
    1차 필터링: 데시벨 기반 빠른 판단
    """
    if decibel_level < 40:
        return "no_input"  # 소리 없음 → 저장하지 않음
    
    elif decibel_level < 48:
        return "normal_low"  # 정상 (낮은 소리) → 통계만
    
    elif decibel_level >= 48:
        return "needs_analysis"  # 분석 필요 → AI 판단으로
```

**장점**:
- ✅ 빠른 처리 (하드웨어 레벨)
- ✅ 명확한 임계값
- ✅ 초기 데이터 없이도 사용 가능

def second_stage_analysis(audio_data: np.ndarray, decibel_level: float) -> Dict:

**장점**:

### 전략 3: 통계적 검증 (3차 확인)

```python
def third_stage_validation(features: Dict, historical_stats: Dict) -> bool:
    """
    3차 확인: 통계적 검증 (Z-score)
    """
    z_score = abs((features['rms'] - historical_stats['mean']) / historical_stats['std'])
    
    if z_score > 3:  # 3시그마 규칙
        return True  # 이상
    return False  # 정상
```

**장점**:
- ✅ 통계적으로 검증 가능
- ✅ 환경 변화에 적응 가능

## 🔄 통합 하이브리드 저장 플로우

```python
def hybrid_storage_decision(audio_data: np.ndarray, decibel_level: float) -> Dict:
    """
    하이브리드 저장 결정 플로우
    """
    # 1단계: 데시벨 기반 1차 필터링
    if decibel_level < 40:
        return {
            'store': False,
            'reason': 'no_input',
            'action': 'skip'
        }
    
    if decibel_level < 48:
        return {
            'store': False,
            'reason': 'normal_low',
            'action': 'update_statistics_only'
        }
    
    # 2단계: AI 모델 기반 2차 판단
    ai_result = ai_model.predict(audio_data)
    is_anomaly = ai_result.get('is_anomaly', False)
    confidence = ai_result.get('confidence', 0.0)
    
    # 3단계: 신뢰도 기반 판단
    if confidence < 0.6:
        # 불확실한 데이터 → 보류 (전문가 라벨링)
        return {
            'store': True,
            'reason': 'low_confidence',
            'action': 'save_for_labeling',
            'format': 'WAV'
        }
    
    elif is_anomaly:
        # 이상 데이터 → 저장
        return {
            'store': True,
            'reason': 'anomaly_detected',
            'action': 'save_audio',
            'format': 'WAV'
        }
    
    else:
        # 정상 데이터 → 통계만
        return {
            'store': False,
            'reason': 'normal',
            'action': 'update_statistics_only'
        }
```

## 📊 데시벨 기반 구분의 실용성

### 시나리오 1: 압축기 가까이 설치 (무인 아이스크림 매장)

**설정**:
- 센서 위치: 압축기 30cm 이내
- 임계값: 50dB
- 환경: 상대적으로 조용한 실내

**구분 가능성**:
- ✅ **50dB 이상**: 압축기 작동 → 분석 필요
- ✅ **35-50dB**: 정상/배경 소음 → 통계만
- ✅ **35dB 미만**: 소리 없음 → 저장하지 않음

**결과**: **간단히 구분 가능**

---

### 시나리오 2: 센서가 멀리 설치

**설정**:
- 센서 위치: 압축기 2m 이상
- 임계값: 50dB
- 환경: 다양한 배경 소음

**구분 가능성**:
- ⚠️ **50dB 이상**: 압축기 소리인지 배경 소음인지 불명확
- ⚠️ **35-50dB**: 정상인지 이상인지 불명확
- ✅ **35dB 미만**: 소리 없음 → 저장하지 않음

**결과**: **추가 분석 필요**

---

### 시나리오 3: 다양한 환경 노이즈

**설정**:
- 센서 위치: 가까이 설치
- 임계값: 50dB
- 환경: 외부 소음, 진동 등

**구분 가능성**:
- ⚠️ **50dB 이상**: 압축기 소리인지 외부 소음인지 불명확
- ⚠️ **35-50dB**: 정상인지 이상인지 불명확
- ✅ **35dB 미만**: 소리 없음 → 저장하지 않음

**결과**: **AI 모델 필요**
