# 서버 실행 확인 가이드

## 서버가 실행 중인지 확인

로그를 보면 서버가 초기화 중입니다. 완전히 실행되려면 몇 초 더 걸릴 수 있습니다.

### 확인 방법 1: 브라우저에서 접속

서버가 완전히 실행되면 (YAMNet 모델 로드 완료 후) 브라우저에서:

```
http://localhost:5000/static/dashboard-components/esp32-realtime-monitor.html
```

### 확인 방법 2: 터미널 테스트

**새 터미널 창에서 (서버는 실행 상태로 두고):**

```bash
cd /root/smartcompressor-ai-system
source venv/bin/activate
python scripts/test_server_connection.py
```

---

## 서버 실행 완료 확인

서버가 완전히 실행되면 다음과 같은 메시지가 표시됩니다:

```
 * Running on http://0.0.0.0:5000
 * Debug mode: on
```

이 메시지가 보이면 서버가 정상 실행 중입니다!

서버 실행 후 브라우저에서:

## 문제 해결

### "This site can't be reached" 오류

1. 서버가 완전히 실행되었는지 확인 (YAMNet 로드 완료 대기)
2. 포트가 다른 프로세스에 의해 사용 중인지 확인
3. WSL 네트워크 설정 확인

### 서버가 계속 로딩 중

YAMNet 모델 로드는 처음 실행 시 시간이 걸립니다 (약 10-30초).
로그에 `* Running on http://0.0.0.0:5000` 메시지가 나타날 때까지 기다리세요.
