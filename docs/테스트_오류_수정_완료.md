# 테스트 오류 수정 완료

## 🔧 수정 내용

### 문제
`baseline_manager.py` 파일에서 `Optional`을 import하지 않아 발생한 오류:
```
NameError: name 'Optional' is not defined
```

### 해결
`services/anomaly_detection_modules/baseline_manager.py` 파일의 39번째 줄을 수정:

**수정 전:**
```python
from typing import Dict, List
```

**수정 후:**
```python
from typing import Dict, List, Optional
```

## 💡 참고

- `Optional[Dict]`는 "Dict 또는 None"을 의미하는 타입 힌트입니다.
- Python 3.9+에서는 `Dict | None` 형태로도 사용할 수 있지만, 호환성을 위해 `Optional`을 사용했습니다.
