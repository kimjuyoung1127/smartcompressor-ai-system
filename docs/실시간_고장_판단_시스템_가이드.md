# 실시간 고장 판단 시스템 가이드

## 개요

들어오는 소리를 **오픈소스 AI + 간단한 알고리즘**으로 즉시 고장/비고장 판단하는 경량 시스템입니다.

**데이터 축적 없이 바로 사용 가능**하며, 나중에 데이터가 쌓이면 점진적으로 정확도를 개선할 수 있습니다.

---

## 예상 정확도

### 단일 방법
- **오픈소스 모델 (YAMNet)**: 약 70-80%
  - 일반적인 사운드 분류에 특화
  - 이상 소리 관련 키워드 매칭
  
- **특징 기반 알고리즘**: 약 75-85%
  - 에너지, 주파수 특성, ZCR 등 도메인 특화
  - 압축기 소리 패턴에 맞춘 임계값

### 앙상블 (두 방법 결합)
- **최종 정확도**: 약 **80-90%**
  - 오픈소스 모델: 40% 가중치
  - 특징 기반: 60% 가중치

---

## 시스템 구성

### 1. RealtimeAnomalyDetector (`ai/realtime_anomaly_detector.py`)
- 오픈소스 사전 훈련 모델 (YAMNet) 사용
- 특징 기반 알고리즘 (에너지, 주파수, ZCR 등)
- 두 방법을 앙상블하여 최종 판단

### 2. RealtimeFailureDetectionService (`services/realtime_failure_detection_service.py`)
- 실시간 오디오 처리
- 알림 관리
- 통계 수집

### 3. API 라우트 (`routes/realtime_detection_routes.py`)
- REST API 엔드포인트
- ESP32와 통신

---

## 사용 방법

### Python에서 직접 사용

```python
from ai.realtime_anomaly_detector import RealtimeAnomalyDetector
import numpy as np

# 초기화
detector = RealtimeAnomalyDetector(
    sample_rate=16000,
    window_size=2.0,  # 2초 윈도우
    use_pretrained_model=True  # YAMNet 사용
)

# 오디오 데이터 (numpy array)
audio_data = np.array([...])  # 실제 오디오 샘플

# 고장 판단
result = detector.detect(audio_data)

print(f"고장 여부: {result['is_failure']}")
print(f"신뢰도: {result['confidence']:.2%}")
print(f"이상 점수: {result['score']:.2f}")
```

### 서비스 사용

```python
from services.realtime_failure_detection_service import RealtimeFailureDetectionService

service = RealtimeFailureDetectionService()

result = service.process_audio(audio_data, device_id="ESP32_001")

if result['should_alert']:
    print("⚠️ 고장 감지 - 알림 필요!")
```

### API 사용 (ESP32에서)

```bash
# POST 요청
curl -X POST http://localhost:5000/api/realtime/detect \
  -H "Content-Type: application/json" \
  -d '{
    "audio_data": [0.1, 0.2, 0.3, ...],
    "device_id": "ESP32_001",
    "sample_rate": 16000
  }'

# 응답
{
  "success": true,
  "result": {
    "is_failure": false,
    "confidence": 0.85,
    "score": 0.25,
    "should_alert": false,
    "processing_time_ms": 15.2
  }
}
```

## 특징 추출 항목

1. **에너지 특징**
   - RMS 에너지
   - 에너지 비율 (정상 대비)

2. **주파수 도메인**
   - 스펙트럼 중심
   - 스펙트럼 롤오프
   - 고주파 에너지 비율

3. **Zero Crossing Rate (ZCR)**
   - 날카로운 소음 감지

4. **MFCC**
   - 음성 인식 특징

---

## 임계값 설정

현재 기본 임계값:
- `energy_ratio`: 2.0 (에너지가 정상의 2배 이상)
- `spectral_centroid_std`: 500.0 (주파수 변동이 클 때)
- `zcr_ratio`: 1.5 (ZCR이 정상의 1.5배 이상)
- `high_freq_energy`: 0.3 (고주파 에너지 비율)

실제 사용 환경에 맞게 조정 가능합니다.

## 동적 조정

시스템은 최근 10개 정상 샘플을 기반으로 정상 기준값을 자동 업데이트합니다:
- 정상 에너지 평균
- 정상 ZCR 평균

이를 통해 환경 변화에 자동으로 적응합니다.
