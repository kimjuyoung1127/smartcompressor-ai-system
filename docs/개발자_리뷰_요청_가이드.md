# 개발자 리뷰 요청 가이드

## 🎯 목표
개발한 ESP32 실시간 모니터링 시스템을 개발자에게 확인 요청

## 📋 방법 1: GitHub 웹에서 리뷰어 지정 (가장 쉬움) ⭐

### 단계별 가이드

1. **PR 페이지로 이동**
   ```
   https://github.com/SEONBEOM-Kim/smartcompressor-ai-system/pull/6
   ```

2. **오른쪽 사이드바에서 "Reviewers" 클릭**
   - "Reviewers" 섹션 찾기
   - "+" 버튼 또는 "Add reviewers" 클릭

3. **개발자 선택**
   - 개발자의 GitHub 사용자명 입력
   - 선택 후 "Request review" 클릭

4. **코멘트 추가 (선택사항)**
   - PR 설명에 다음 내용 추가:
   ```markdown
   ## 리뷰 요청 🙏
   
   @[개발자_사용자명] 님, ESP32 실시간 모니터링 시스템 개발 완료했습니다.
   확인 부탁드립니다!
   
   ### 주요 기능
   - ESP32 실시간 판단 서비스
   - 데시벨 기반 임계값 처리
   - 디바이스 선택 기능
   - 실시간 대시보드
   - MIMII 모델 통합 (92% 정확도)
   
   ### 테스트 방법
   - 서버 실행: `python scripts/start_server_minimal.py`
   - 대시보드: `http://172.27.98.13:5000/static/dashboard-components/esp32-realtime-monitor.html`
   ```

## 📋 방법 2: GitHub CLI로 리뷰 요청

### WSL 터미널에서:

```bash
# PR에 리뷰어 추가
gh pr edit 6 --add-reviewer [개발자_사용자명]

# PR에 코멘트 추가
gh pr comment 6 --body "안녕하세요! ESP32 실시간 모니터링 시스템 개발 완료했습니다. 확인 부탁드립니다! 🙏"
```

## 📋 방법 3: PR 코멘트로 직접 요청

### PR 페이지에서:

1. PR #6 페이지 하단의 "Add comment" 클릭
2. 다음 메시지 입력:

```markdown
@[개발자_사용자명] 님, 안녕하세요!

ESP32 실시간 모니터링 시스템 개발을 완료했습니다.
확인 부탁드립니다! 🙏

### 주요 구현 사항
- ✅ ESP32 실시간 판단 서비스
- ✅ 데시벨 기반 임계값 처리 (35-40dB: 소리 없음, 48dB 이상: 판단 시작)
- ✅ 디바이스 선택 기능
- ✅ 실시간 대시보드 구현
- ✅ MIMII 모델 통합 (92% 정확도)
- ✅ 보류 라벨링 시스템

### 테스트 방법
1. 서버 실행: `python scripts/start_server_minimal.py`
2. 대시보드 접속: `http://172.27.98.13:5000/static/dashboard-components/esp32-realtime-monitor.html`

### 참고사항
- 아직 main 브랜치에 머지하지 않았습니다 (검토 후 머지 예정)
- 서버 비용 발생 안 함 (다른 브랜치이므로 자동 배포 안 됨)

감사합니다!
```

3. "Comment" 버튼 클릭

PR 링크와 함께 메시지 전송:

```
안녕하세요!

ESP32 실시간 모니터링 시스템 개발을 완료했습니다.
PR 확인 부탁드립니다!

- 데시벨 기반 임계값 처리
- 디바이스 선택 기능
- 실시간 대시보드
- MIMII 모델 통합 (92% 정확도)

감사합니다!
```

## ✅ 확인 방법

리뷰 요청이 성공했는지 확인:

```bash
# GitHub CLI로 PR 정보 확인
gh pr view 6

# 리뷰어 목록 확인
gh pr view 6 --json reviewers
```

- **PR 설명 업데이트**: PR 설명에 리뷰 요청 내용을 추가하면 좋습니다
