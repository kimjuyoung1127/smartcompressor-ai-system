# 테스트 실행 가이드

## 🧪 테스트 실행 방법

### 방법 1: WSL에서 직접 실행 (권장)

```bash
# WSL 터미널에서 실행
cd /root/smartcompressor-ai-system

# 가상 환경 활성화 (있는 경우)
source venv/bin/activate

# pytest 설치 (처음 한 번만)
pip install pytest pytest-cov pytest-asyncio

# 테스트 실행
pytest tests/

# 또는 스크립트 사용
bash scripts/run_tests.sh
```

### 방법 2: PowerShell에서 WSL 실행

```powershell
# PowerShell에서 실행
wsl bash scripts/run_tests.sh

# 또는 직접 실행
wsl python3 -m pytest tests/
```

### 방법 3: 스크립트 사용 (PowerShell)

```powershell
# PowerShell 스크립트 실행
.\scripts\run_tests.ps1
```

## 📋 테스트 옵션

### 모든 테스트 실행
```bash
pytest tests/
```

### 특정 모듈 테스트
```bash
pytest tests/test_anomaly_detection_modules/
```

### 커버리지 포함
```bash
pytest tests/ --cov=services/anomaly_detection_modules --cov-report=html
```

### 커버리지 임계값 확인
```bash
pytest tests/ --cov=services/anomaly_detection_modules --cov-fail-under=70
```

### 상세 출력
```bash
pytest tests/ -v
```

## 🔧 문제 해결

### pytest가 설치되지 않은 경우

```bash
# WSL에서 실행
pip install pytest pytest-cov pytest-asyncio

# 또는 requirements.txt에서 설치
pip install -r requirements.txt
```

### 가상 환경이 없는 경우

```bash
# 가상 환경 생성
python3 -m venv venv

# 가상 환경 활성화
source venv/bin/activate

# 패키지 설치
pip install -r requirements.txt
```

### import 오류가 발생하는 경우

```bash
# 프로젝트 루트에서 실행 확인
pwd  # /root/smartcompressor-ai-system 확인

# PYTHONPATH 설정
export PYTHONPATH=/root/smartcompressor-ai-system:$PYTHONPATH
pytest tests/
```
