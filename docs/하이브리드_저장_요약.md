# 하이브리드 저장 서비스 요약

## 🔍 질문 답변

### Q1: 샘플링 간격과 파일 용량
**답변**: 한 개 파일 용량은 동일 (160 KB), 수집 횟수가 다름
- 60초 간격: 1,440개/일 → 230.4 MB/일
- 5분 간격: 288개/일 → 46.1 MB/일

### Q2: 전체 녹음본인가?
**답변**: 아니요. **5초 샘플만** 주기적으로 수집합니다.

### Q3: 로컬 저장 장치 설치 필요?
**답변**: 아니요. **EC2 서버의 디스크(EBS)**에 저장되므로 별도 설치 불필요.

---

## 💾 하이브리드 저장 전략

### 저장 방식

#### 이상 감지 시
- ✅ 오디오 파일 저장 (MP3 압축)
- ✅ AI 분석 결과 저장
- ✅ 특징 데이터 저장
- ✅ 메타데이터 저장

#### 정상 데이터
- ❌ 오디오 파일 저장하지 않음
- ✅ 통계만 업데이트 (하루 1-2회)
- ✅ 특징 데이터 10%만 샘플링 저장 (AI 학습용)

## 🎯 AI 학습 최적화

### 수집되는 데이터
1. **이상 데이터**: 모든 이상 샘플 저장
2. **불확실한 데이터**: 신뢰도 < 0.6인 데이터 저장
3. **정상 데이터 샘플**: 10%만 특징 데이터 저장
