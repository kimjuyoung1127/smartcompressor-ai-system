# 센서 2개 24시간 소리 녹음 비용 계산

## 📊 데이터 크기 계산

### 기본 가정
- **센서 수**: 2개
- **녹음 시간**: 24시간/일
- **샘플링 레이트**: 16kHz (일반적)
- **비트 깊이**: 16bit
- **채널**: 모노 (1채널)
- **압축**: WAV (무압축) 또는 MP3 (압축)

---

## 💾 저장 공간 계산

### 시나리오 1: 전체 녹음 (무압축 WAV)

**1개 센서당 1초당 데이터 크기**:
```
16,000 samples/sec × 2 bytes = 32 KB/sec
```

**1개 센서당 1일 데이터 크기**:
```
32 KB/sec × 60 sec × 60 min × 24 hours = 2.76 GB/일
```

**센서 2개 1일 총 데이터 크기**:
```
2.76 GB × 2 = 5.52 GB/일
```

**1개월 (30일) 데이터 크기**:
```
5.52 GB × 30 = 165.6 GB/월
```

**1년 데이터 크기**:
```
5.52 GB × 365 = 2,014.8 GB ≈ 2 TB/년
```

---

### 시나리오 2: 샘플링 방식 (5초 간격, 현재 시스템)

**현재 시스템**: 5초 오디오 샘플을 주기적으로 수집

**1개 센서당 1회 샘플 데이터 크기**:
```
32 KB/sec × 5 sec = 160 KB/샘플
```

**1분당 샘플 수** (60초 간격):
```
60초 / 60초 = 1 샘플/분
```

**1일 샘플 수**:
```
1 샘플/분 × 60 분 × 24 시간 = 1,440 샘플/일
```

**1개 센서당 1일 데이터 크기**:
```
160 KB × 1,440 = 230.4 MB/일
```

**센서 2개 1일 총 데이터 크기**:
```
230.4 MB × 2 = 460.8 MB/일 ≈ 0.46 GB/일
```

**1개월 (30일) 데이터 크기**:
```
0.46 GB × 30 = 13.8 GB/월
```

**1년 데이터 크기**:
```
0.46 GB × 365 = 167.9 GB/년
```

---

### 시나리오 3: 압축 방식 (MP3, 128kbps)

**1개 센서당 1일 데이터 크기** (MP3 압축):
```
128 kbps × 60 sec × 60 min × 24 hours / 8 bits = 1.38 GB/일
```

**센서 2개 1일 총 데이터 크기**:
```
1.38 GB × 2 = 2.76 GB/일
```

**1개월 (30일) 데이터 크기**:
```
2.76 GB × 30 = 82.8 GB/월
```

**1년 데이터 크기**:
```
2.76 GB × 365 = 1,007.4 GB ≈ 1 TB/년
```

---

### 시나리오 4: 스마트 저장 (AI 분석 결과만 저장)

**현재 시스템**: `SmartStorageService` 사용
- 정상 데이터는 저장하지 않음
- 이상 감지 시에만 저장
- 특징 데이터만 압축 저장

**가정**:
- 이상 발생률: 5% (하루 72개 샘플)
- 특징 데이터 크기: 1 KB/샘플 (압축)

**1개 센서당 1일 데이터 크기**:
```
72 샘플 × 1 KB = 72 KB/일
```

**센서 2개 1일 총 데이터 크기**:
```
72 KB × 2 = 144 KB/일
```

**1개월 (30일) 데이터 크기**:
```
144 KB × 30 = 4.32 MB/월
```

**1년 데이터 크기**:
```
144 KB × 365 = 52.56 MB/년
```
