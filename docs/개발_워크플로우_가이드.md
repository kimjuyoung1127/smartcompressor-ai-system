## 🚀 개발 환경 설정

### 방법 1: Docker 사용 (권장)

**장점**: 환경 설정 불필요, 즉시 시작 가능

```bash
# 1. 저장소 클론
git clone https://github.com/SEONBEOM-Kim/smartcompressor-ai-system.git
cd smartcompressor-ai-system

# 2. 환경 변수 설정
cp env.example .env
# .env 파일 편집 (필요시)

# 3. Docker 실행
docker-compose up -d

# 4. 서비스 확인
curl http://localhost:5000/api/health
```

**소요 시간**: 약 5분

---

### 방법 2: 수동 설치

**장점**: 더 세밀한 제어 가능

```bash
# 1. 저장소 클론
git clone https://github.com/SEONBEOM-Kim/smartcompressor-ai-system.git
cd smartcompressor-ai-system

# 2. Python 가상 환경 생성
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 의존성 설치
pip install --upgrade pip
pip install -r requirements.txt

# 4. Node.js 의존성 설치
npm install

# 5. 환경 변수 설정
cp env.example .env
# .env 파일 편집

# 6. 데이터베이스 초기화
python -c "from models.database import init_db; init_db()"

# 7. 서버 실행
python app.py
```

**소요 시간**: 약 15-20분

## 👤 개인 개발 워크플로우

### 1. 새 기능 개발

```bash
# 1. 최신 코드 가져오기
git checkout main
git pull origin main

# 2. 새 기능 브랜치 생성
git checkout -b feature/my-new-feature

# 3. 개발 및 테스트
# ... 코드 작성 ...
pytest tests/ -v

# 4. 커밋
git add .
git commit -m "feat: 새 기능 추가"

# 5. 푸시
git push origin feature/my-new-feature
```

---

### 2. 버그 수정

```bash
# 1. 버그 브랜치 생성
git checkout -b fix/bug-description

# 2. 버그 수정 및 테스트

pytest tests/ -v

# 3. 커밋 및 푸시
git add .
git commit -m "fix: 버그 수정"
git push origin fix/bug-description
```

---

```bash
# - 팀원에게 리뷰 요청

git checkout feature/my-new-feature
# ... 수정 ...
git add .
git commit -m "refactor: 리뷰 피드백 반영"
git push origin feature/my-new-feature

# 4. 승인 후 머지
# GitHub에서 머지 버튼 클릭
```

---

### 2. 브랜치 전략

```
main (프로덕션)
  ├── develop (개발)
  │   ├── feature/esp32-integration
  │   ├── feature/dashboard-improvement
  │   └── fix/bug-fix
  └── hotfix/critical-fix
```

**규칙**:
- `main`: 프로덕션 코드만
- `develop`: 개발 중인 코드
- `feature/*`: 새 기능
- `fix/*`: 버그 수정
- `hotfix/*`: 긴급 수정

---

### 3. 충돌 해결

```bash
# 1. 최신 코드 가져오기
git checkout develop
git pull origin develop

# 2. 브랜치에 머지
git checkout feature/my-feature
git merge develop

# 3. 충돌 해결
# 충돌 파일 편집
git add .
git commit -m "merge: develop 브랜치 머지"
```

## 🔄 기능 이식 가이드

### 시나리오 1: 기존 서비스에 이식

#### 단계 1: 파일 복사

```bash
# 핵심 파일 복사
cp services/anomaly_detection_modules/ your-project/services/
cp services/esp32_integrated_detection_service.py your-project/services/
cp routes/esp32_integrated_routes.py your-project/routes/
```

#### 단계 2: 의존성 추가

```bash
# requirements.txt에 추가
pip install -r requirements.txt
```

#### 단계 3: 라우트 등록

```python
# app.py 또는 main.py에 추가
from routes.esp32_integrated_routes import esp32_integrated_bp
app.register_blueprint(esp32_integrated_bp, url_prefix='/api/esp32')
```

#### 단계 4: 데이터베이스 마이그레이션

```bash
# 데이터베이스 스키마 확인
python -c "from models.database import init_db; init_db()"
```

#### 단계 5: 테스트

```bash
# 통합 테스트 실행
pytest tests/test_integration/ -v
```

---

### 시나리오 2: 새 프로젝트에 이식

#### 단계 1: 프로젝트 구조 생성

```bash
mkdir my-new-project
cd my-new-project

# 프로젝트 구조 생성
mkdir -p services routes static/pages tests
```

#### 단계 2: 핵심 파일 복사

```bash
# 모듈화된 이상 감지 시스템
cp -r services/anomaly_detection_modules/ services/

# 서비스 파일
cp services/esp32_integrated_detection_service.py services/
cp services/realtime_dashboard_service.py services/

# 라우트 파일
cp routes/esp32_integrated_routes.py routes/
cp routes/realtime_dashboard_routes.py routes/

# 대시보드 UI
cp static/pages/realtime_monitoring_dashboard.html static/pages/
```

#### 단계 3: 의존성 설치

```bash
# requirements.txt 생성
cat > requirements.txt << EOF
flask>=2.3.0
flask-cors>=4.0.0
numpy>=1.24.0
librosa>=0.10.0
scikit-learn>=1.3.0
pytest>=7.4.0
EOF

pip install -r requirements.txt
```

#### 단계 4: 앱 초기화

```python
# app.py 생성
from flask import Flask
from routes.esp32_integrated_routes import esp32_integrated_bp
from routes.realtime_dashboard_routes import realtime_dashboard_bp

app = Flask(__name__)
app.register_blueprint(esp32_integrated_bp, url_prefix='/api/esp32')
app.register_blueprint(realtime_dashboard_bp, url_prefix='/api/realtime')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)
```

#### 단계 5: 테스트

```bash
# 서버 실행
python app.py

# API 테스트
curl http://localhost:5000/api/esp32/integrated/health
```

## 🛠️ 문제 해결

### 일반적인 문제

#### 문제 1: 의존성 설치 오류

```bash
# 해결 방법
pip install --upgrade pip
pip install -r requirements.txt --no-cache-dir
```

#### 문제 2: 포트 충돌

```bash
# 해결 방법
# app.py에서 포트 변경
app.run(host='0.0.0.0', port=5001)  # 5000 대신 5001 사용
```

#### 문제 3: 모듈 import 오류

```bash
# 해결 방법
# PYTHONPATH 설정
export PYTHONPATH="${PYTHONPATH}:$(pwd)"
# 또는
python -m pip install -e .
```

#### 문제 4: 데이터베이스 연결 오류

```bash
# 해결 방법
# 데이터베이스 초기화
python -c "from models.database import init_db; init_db()"
```

### Docker 관련 문제

#### 문제 1: 컨테이너가 시작되지 않음

```bash
# 해결 방법
docker-compose logs app
docker-compose up -d --build
```

#### 문제 2: 볼륨 마운트 오류

```bash
# 해결 방법
# 권한 확인
ls -la data/
# 필요시 권한 수정
chmod -R 755 data/
```
