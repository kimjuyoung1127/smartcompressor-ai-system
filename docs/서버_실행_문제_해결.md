# 서버 실행 문제 해결 가이드

## 문제: embedded null byte 오류

`.env` 파일에 null 바이트(`\x00`)가 포함되어 있어서 발생하는 오류입니다.

---

## 해결 방법

### 방법 1: .env 파일 수정 (권장)

**WSL 터미널에서:**

```bash
cd /root/smartcompressor-ai-system
source venv/bin/activate
python scripts/fix_env_file.py
```

이 스크립트는 `.env` 파일의 null 바이트를 자동으로 제거합니다.

### 방법 2: 안전 모드로 서버 실행

null 바이트 오류를 무시하고 서버를 실행:

```bash
cd /root/smartcompressor-ai-system
source venv/bin/activate
python scripts/start_server_safe.py
```

### 방법 3: .env 파일 재생성

`.env` 파일을 백업하고 새로 생성:

```bash
cd /root/smartcompressor-ai-system
cp .env .env.backup
# .env 파일을 텍스트 에디터로 열어서 null 바이트가 있는 줄 삭제
```

---

## 빠른 해결

**가장 빠른 방법:**

```bash
cd /root/smartcompressor-ai-system
source venv/bin/activate

# 1. .env 파일 수정
python scripts/fix_env_file.py

# 2. 서버 실행
python scripts/start_server_safe.py
```

## 추가 참고

- `.env` 파일은 텍스트 파일이어야 합니다
- 바이너리 데이터나 null 바이트가 포함되면 오류가 발생합니다
- 문제가 계속되면 `.env` 파일을 삭제하고 `api_keys_template.env`를 참고하여 새로 만드세요
