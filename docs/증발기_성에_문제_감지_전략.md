# 증발기/라인 성에 문제 감지 전략

## 🎯 핵심 문제

**증발기/라인에 성에가 많이 끼고 팬에도 성에가 많이 껴서 제대로 냉매 증발이 일어나지 않는 문제**

**결과**:
- 열교환 제대로 안 됨
- 시원해지지 않음
- 압축기 계속 돌음 (이상 작동)

---

## 🔬 문제의 물리적 특성

### 증발기 성에 문제의 소리 패턴

#### 1. 압축기 작동 시간 증가
- **정상**: 온도 도달 시 자동 정지
- **성에 문제**: 온도 도달 안 됨 → 계속 작동
- **소리 패턴**: 연속 작동 시간 증가

#### 2. 주파수 패턴 변화
- **정상**: 주기적 on/off 패턴
- **성에 문제**: 연속 작동 → 주파수 패턴 변화
- **고주파 성분**: 과부하로 인한 고주파 증가

#### 3. 에너지 패턴 변화
- **정상**: 주기적 에너지 변화
- **성에 문제**: 지속적 높은 에너지
- **RMS 에너지**: 지속적으로 높음

```python
def detect_continuous_operation(audio_data: np.ndarray, baseline: Dict) -> Dict:
    """
    연속 작동 패턴 감지 (증발기 성에 문제)
    """
    features = extract_features(audio_data)
    
    # 1. RMS 에너지 지속적 높음
    if features['rms_energy'] > baseline['rms_energy_mean'] * 1.5:
        continuous_score += 0.3
    
    # 2. 주파수 패턴 변화 (연속 작동)
    if features['spectral_centroid'] > baseline['spectral_centroid_mean'] * 1.2:
        continuous_score += 0.3
    
    # 3. 고주파 에너지 증가 (과부하)
    if features['high_freq_energy_ratio'] > baseline['high_freq_energy_ratio_mean'] * 1.5:
        continuous_score += 0.4
    
    # 4. 패턴 안정성 감소 (정상 on/off 패턴 없음)
    if features['pattern_regularity'] < baseline['pattern_regularity_mean'] * 0.7:
        continuous_score += 0.2
    
    return {
        'is_continuous_operation': continuous_score > 0.7,
        'continuous_score': continuous_score,
        'failure_type': 'evaporator_frost' if continuous_score > 0.7 else 'normal'
    }
```

**장점**:
- ✅ 즉시 감지 가능 (실시간)
- ✅ 스펙트럼 이상 점수로 감지 가능
- ✅ 추가 데이터 수집 불필요

**단점**:
- ⚠️ 기온 변화와 구분 어려움
- ⚠️ 정확도 70-80% (기온 보정 필요)
