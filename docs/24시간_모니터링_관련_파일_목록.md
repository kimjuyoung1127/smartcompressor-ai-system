주영님이 개발한 24시간 자동 모니터링 기능과 관련된 파일 목록입니다.

## 🔴 핵심 24시간 모니터링 서비스

### 1. `services/realtime_monitoring.py` ⭐ **메인 24시간 모니터링 서비스**
- **설명**: 24시간 무인 냉동고 모니터링 서비스
- **기능**:
  - `start_monitoring()`: 24시간 모니터링 시작
  - `stop_monitoring()`: 모니터링 중지
  - `_monitoring_loop()`: 백그라운드 스레드로 지속적 모니터링
  - `check_interval`: 모니터링 간격 (기본 60초)
  - SQLite 데이터베이스에 모니터링 로그 저장
  - 이상 감지 시 알림 처리
- **상태**: `is_running` 플래그로 모니터링 활성화 여부 관리
- **⚠️ 이 파일이 24시간 모니터링의 핵심입니다!**

## 🧠 통합 AI 시스템 (24시간 모니터링 데이터 활용)

## ⚠️ 주의사항

### 24시간 모니터링 중단 방법

1. **`services/realtime_monitoring.py`**에서:
   ```python
   # 모니터링 중지
   monitoring_service.stop_monitoring()
   ```

2. **`ai/integrated_ai_system.py`**에서:
   ```python
   # 연속 모니터링 중지
   system.stop_continuous_monitoring()
   ```

3. **서버 시작 시 자동 실행 방지**:
   - `app.py` 또는 서버 시작 스크립트에서 `start_monitoring()` 호출 제거
   - 환경 변수로 모니터링 활성화 여부 제어

## 🔍 확인 필요 사항

1. **서버 시작 시 자동 실행 여부**
   - `app.py`에서 `monitoring_service.start_monitoring()` 호출 확인
   - 다른 서비스에서 자동 시작하는지 확인

2. **백그라운드 프로세스**
   - 현재 실행 중인 모니터링 스레드 확인
   - `ps aux | grep monitoring` 명령으로 확인

3. **데이터베이스**
   - `data/monitoring.db` 파일 생성 여부 확인
   - 모니터링 로그가 계속 쌓이고 있는지 확인
