## 💡 참고사항

### 현재 상태
- 24시간 모니터링 기능은 **중단** 상태
- 서버 시작 시 자동으로 모니터링이 시작되지 않음
- API를 통한 수동 시작/중지는 여전히 가능

### 복구 방법
필요시 `app.py`의 주석을 제거하면 다시 자동 시작됩니다:
```python
# 주석 제거
sensor_monitoring_service.start_monitoring()
```
