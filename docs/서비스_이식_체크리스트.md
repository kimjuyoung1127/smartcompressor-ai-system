## 🐛 문제 해결

### 일반적인 문제

#### 문제 1: Import 오류

**증상**: `ModuleNotFoundError`

**해결**:
```bash
# PYTHONPATH 설정
export PYTHONPATH="${PYTHONPATH}:$(pwd)"

# 또는 __init__.py 파일 확인
touch services/anomaly_detection_modules/__init__.py
```

#### 문제 2: 의존성 충돌

**증상**: 패키지 버전 충돌

**해결**:
```bash
# 가상 환경 사용
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

#### 문제 3: 데이터베이스 연결 오류

**증상**: `sqlite3.OperationalError` 또는 `psycopg2.OperationalError`

**해결**:
```bash
# 데이터베이스 파일 권한 확인
ls -la data/*.db

# 데이터베이스 초기화
python -c "from models.database import init_db; init_db()"
```

#### 문제 4: 포트 충돌

**증상**: `Address already in use`

**해결**:
```python
# app.py에서 포트 변경
app.run(host='0.0.0.0', port=5001)  # 5000 대신 다른 포트
```
