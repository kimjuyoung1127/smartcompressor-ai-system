# 개발자 공유 브랜치 가이드

## ✅ 안전한 브랜치 전략

### 현재 설정 확인
- ✅ **자동 배포는 `main` 브랜치에만 적용됨**
- ✅ 다른 브랜치에 커밋해도 **서버 비용 발생 안 함**
- ✅ EC2 서버는 영향받지 않음

## 🚀 개발자에게 공유하는 방법

### 방법 1: Feature 브랜치 생성 및 공유 (권장)

```bash
# 1. 현재 작업 내용 확인
git status

# 2. 새로운 feature 브랜치 생성
git checkout -b feature/esp32-realtime-detection

# 3. 변경사항 커밋
git add .
git commit -m "feat: ESP32 실시간 모니터링 시스템 구현

- ESP32 실시간 판단 서비스 추가
- 데시벨 기반 임계값 처리 (35-40dB: 소리 없음, 48dB 이상: 판단 시작)
- 디바이스 선택 기능 추가
- 실시간 대시보드 구현
- MIMII 모델 통합 (92% 정확도)
- 보류 라벨링 시스템 구현"

# 4. 브랜치를 원격 저장소에 푸시
git push origin feature/esp32-realtime-detection

# 5. GitHub에서 Pull Request 생성
# 또는 개발자에게 브랜치 이름 공유
```

### 방법 2: Pull Request 생성

1. **GitHub에서 PR 생성:**
   - GitHub 저장소로 이동
   - "Compare & pull request" 클릭
   - `feature/esp32-realtime-detection` → `main` 브랜치로 PR 생성
   - 개발자에게 PR 링크 공유

2. **PR 설명 작성 예시:**
   ```markdown
   ## ESP32 실시간 모니터링 시스템
   
   ### 주요 기능
   - ✅ ESP32 실시간 판단 서비스
   - ✅ 데시벨 기반 임계값 처리
   - ✅ 디바이스 선택 기능
   - ✅ 실시간 대시보드
   - ✅ MIMII 모델 통합
   
   ### 테스트 방법
   1. 서버 실행: `python scripts/start_server_minimal.py`
   2. 대시보드 접속: `http://172.27.98.13:5000/static/dashboard-components/esp32-realtime-monitor.html`
   
   ### 주의사항
   - ⚠️ 아직 main 브랜치에 머지하지 않음 (검토 후 머지 예정)
   ```

### 방법 3: 브랜치 직접 공유

```bash
# 브랜치 푸시 후 개발자에게 알림
# "feature/esp32-realtime-detection 브랜치 확인 부탁드립니다"
```

## 📋 브랜치 명명 규칙

### 권장 브랜치 이름
- `feature/esp32-realtime-detection` - 기능 개발
- `feature/device-selection` - 디바이스 선택 기능
- `dev/algorithm-v1` - 알고리즘 1차 버전
- `test/esp32-integration` - 테스트용

### 피해야 할 브랜치 이름
- ❌ `main` - 메인 브랜치 (자동 배포됨)
- ❌ `master` - 메인 브랜치
- ❌ `production` - 프로덕션 브랜치

## 🔒 안전성 확인

### 자동 배포 설정 확인
```yaml
# .github/workflows/auto-deploy.yml
on:
  push:
    branches: [ main ]  # ✅ main 브랜치에만 적용
```

### 서버 배포 스크립트 확인
```bash
# scripts/deploy-ec2-pm2.sh
git pull origin main  # ✅ main 브랜치만 pull
```

다음 명령어로 현재 브랜치 확인:

```bash
# 현재 브랜치 확인
git branch

# 원격 브랜치 확인
git branch -r

# 모든 브랜치 확인
git branch -a
```

## 🎯 추천 워크플로우

1. **개발 중:**
   ```bash
   git checkout -b feature/esp32-realtime-detection
   # 개발 작업...
   git add .
   git commit -m "작업 내용"
   git push origin feature/esp32-realtime-detection
   ```

2. **개발자에게 공유:**
   - GitHub PR 생성 또는 브랜치 이름 공유

3. **검토 후 머지:**
   ```bash
   # main 브랜치로 전환
   git checkout main
   
   # feature 브랜치 머지
   git merge feature/esp32-realtime-detection
   
   # main 브랜치 푸시 (이때만 자동 배포됨)
   git push origin main
   ```

## 💡 참고

- **다른 브랜치에 커밋해도 서버는 안전합니다**
- **main 브랜치에 머지하기 전까지는 자동 배포되지 않습니다**
- **개발자 검토 후 main에 머지하는 것이 안전합니다**
