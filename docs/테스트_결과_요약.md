## 💡 경고 (Warning)

많은 테스트에서 `return` 대신 `assert`를 사용해야 한다는 경고가 있습니다. 이는 테스트 동작에는 영향을 주지 않지만, pytest 모범 사례를 따르려면 수정하는 것이 좋습니다.

**예시**:
```python
# 현재 (경고 발생)
def test_something():
    return result == expected

# 권장 (경고 없음)
def test_something():
    assert result == expected
```
