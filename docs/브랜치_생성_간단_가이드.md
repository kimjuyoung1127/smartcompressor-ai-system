# 브랜치 생성 간단 가이드

## 🚀 빠른 실행 (로컬 WSL에서)

### 1단계: 변경사항 커밋

```bash
# 현재 디렉토리 확인
cd ~/smartcompressor-ai-system

# 변경사항 확인
git status

# 모든 변경사항 추가
git add .

# 커밋
git commit -m "feat: ESP32 실시간 모니터링 시스템 구현

- ESP32 실시간 판단 서비스 추가
- 데시벨 기반 임계값 처리 (35-40dB: 소리 없음, 48dB 이상: 판단 시작)
- 디바이스 선택 기능 추가
- 실시간 대시보드 구현
- MIMII 모델 통합 (92% 정확도)
- 보류 라벨링 시스템 구현
- 스마트 판단 오케스트레이터 구현"
```

### 2단계: Feature 브랜치 생성

```bash
# Feature 브랜치 생성 및 전환
git checkout -b feature/esp32-realtime-detection-v1
```

### 3단계: 원격 저장소에 푸시

```bash
# 원격 저장소에 푸시
git push -u origin feature/esp32-realtime-detection-v1
```

### 4단계: GitHub에서 PR 생성

1. GitHub 저장소로 이동: https://github.com/SEONBEOM-Kim/smartcompressor-ai-system
2. "Compare & pull request" 버튼 클릭
3. `feature/esp32-realtime-detection-v1` → `main` 브랜치로 PR 생성
4. 개발자에게 PR 링크 공유

## ✅ 확인

브랜치가 생성되었는지 확인:

```bash
# 현재 브랜치 확인
git branch

# 원격 브랜치 확인
git branch -r
```

## 🔒 안전성

- ✅ 다른 브랜치에 커밋해도 서버 비용 발생 안 함
- ✅ 자동 배포는 `main` 브랜치에만 적용됨
- ✅ EC2 서버는 영향받지 않음
