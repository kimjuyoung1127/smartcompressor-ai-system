# 데이터 수집 및 검증 시스템 가이드

## 📋 개요

종합적인 데이터 수집 및 검증 시스템으로, 데이터 품질 검증, 버전 관리, 라벨링 품질 관리를 통합합니다.

### 주요 구성 요소

1. **데이터 품질 검증 시스템** (`data_quality_validator.py`)
   - 기술적 품질 검증
   - 신호 품질 검증
   - 메타데이터 품질 검증

2. **데이터 버전 관리 시스템** (`data_version_manager.py`)
   - 데이터셋 버전 관리
   - 변경 이력 추적
   - 버전 비교

3. **라벨링 품질 관리 시스템** (`labeling_quality_manager.py`)
   - 라벨 일관성 검증
   - 전문가 간 일치도 측정
   - 라벨링 품질 점수 계산

4. **종합 데이터 수집 서비스** (`comprehensive_data_collection_service.py`)
   - 통합 파이프라인
   - 자동 품질 검증
   - 통계 수집

## 🔍 데이터 품질 검증

### 검증 항목

#### 1. 기술적 품질 (40% 가중치)

- **샘플링 레이트**: 16000Hz ~ 48000Hz 권장
- **데이터 길이**: 1초 ~ 10초 권장
- **신호 레벨**: 최대 진폭 100 ~ 30000 범위
- **클리핑**: 클리핑 비율 1% 미만
- **무음 구간**: 무음 비율 90% 미만

#### 2. 신호 품질 (40% 가중치)

- **SNR**: 최소 20dB
- **동적 범위**: 최소 40dB
- **신호 존재 여부**: 유효한 신호 감지

#### 3. 메타데이터 품질 (20% 가중치)

- **필수 필드**: `device_id`, `timestamp`
- **타임스탬프 유효성**: ISO 8601 형식
- **디바이스 ID 유효성**: 최소 3자 이상

### 품질 등급

- **EXCELLENT** (90-100점): 우수한 품질
- **GOOD** (70-89점): 양호한 품질
- **ACCEPTABLE** (50-69점): 허용 가능한 품질
- **POOR** (30-49점): 낮은 품질
- **REJECT** (0-29점): 거부 (사용 불가)

## 🚀 종합 데이터 수집 서비스

### 데이터 수집 및 검증

```python
from services.comprehensive_data_collection_service import comprehensive_data_collection_service

# 데이터 수집 및 자동 검증
result = comprehensive_data_collection_service.collect_and_validate(
    audio_data=audio_array,
    sample_rate=16000,
    device_id="ESP32_001",
    metadata={"location": "store_001"},
    save_path="data/audio/sample.wav"
)

if result['success']:
    print(f"✅ 수집 완료: {result['sample_id']}")
    print(f"품질 점수: {result['quality_result']['overall_score']:.1f}점")
    print(f"품질 등급: {result['quality_result']['quality_level']}")
else:
    print(f"❌ 수집 실패: {result['message']}")
```

### 라벨링 추가

```python
# 라벨링 추가
labeling_result = comprehensive_data_collection_service.add_labeling(
    sample_id=result['sample_id'],
    annotator_id="expert_001",
    label="normal",
    confidence=0.95
)
```

### 통계 조회

## 📊 사용 예제

### 전체 워크플로우

```python
import numpy as np
from services.comprehensive_data_collection_service import comprehensive_data_collection_service

# 1. 오디오 데이터 준비
audio_data = np.array([...])  # 오디오 배열
sample_rate = 16000

# 2. 데이터 수집 및 검증
result = comprehensive_data_collection_service.collect_and_validate(
    audio_data=audio_data,
    sample_rate=sample_rate,
    device_id="ESP32_001",
    save_path="data/audio/sample.wav"
)

# 3. 품질 검증 결과 확인
if result['success']:
    quality = result['quality_result']
    
    if quality['quality_level'] == 'excellent':
        # 4. 라벨링 추가
        comprehensive_data_collection_service.add_labeling(
            sample_id=result['sample_id'],
            annotator_id="expert_001",
            label="normal",
            confidence=0.95
        )
        
        print("✅ 데이터 수집 및 라벨링 완료")
    else:
        print(f"⚠️ 품질 등급이 낮습니다: {quality['quality_level']}")
        print(f"문제점: {', '.join(quality['issues'])}")
else:
    print(f"❌ 데이터 수집 실패: {result['message']}")
```

    min_sample_rate=8000,      # 최소 샘플링 레이트

    max_duration=10.0,         # 최대 오디오 길이

)

## 💡 모범 사례

1. **정기적인 품질 검증**
   - 수집된 데이터의 품질을 정기적으로 검증
   - 품질 문제가 있는 데이터는 즉시 제거 또는 재수집

2. **버전 관리**
   - 주요 변경사항마다 새 버전 생성
   - 버전별 메타데이터 상세 기록

3. **라벨링 가이드라인**
   - 명확한 라벨링 가이드라인 제공
   - 전문가 간 일치도 정기적으로 측정

4. **통계 모니터링**
   - 수집 통계를 정기적으로 모니터링
   - 품질 통과율 및 라벨링 완료율 추적
