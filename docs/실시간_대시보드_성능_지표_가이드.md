# 실시간 모니터링 대시보드 - 성능 지표 가이드

## 📋 개요

실시간 모니터링 대시보드에 성능 지표 시각화를 추가하여 시스템 성능을 실시간으로 모니터링할 수 있습니다.

### 추가된 기능

1. **성능 메트릭 카드**
   - 평균 처리 시간 (ms)
   - 처리량 (개/초)
   - 품질 통과율 (%)
   - 라벨링 완료율 (%)

2. **성능 차트**
   - 처리 시간 추이 (시간별 변화)
   - 처리량 추이 (시간별 변화)

3. **통합 통계**
   - ESP32 통합 서비스 통계
   - Active Learning 통계
   - 데이터 수집 통계

---

## 🎯 성능 지표 설명

### 1. 평균 처리 시간 (Average Processing Time)

**의미**: 하나의 오디오 샘플을 처리하는 데 걸리는 평균 시간

**단위**: 밀리초 (ms)

**목표값**: 50ms 이하

**해석**:
- **< 50ms**: 우수 ✅
- **50-100ms**: 양호 ⚠️
- **> 100ms**: 개선 필요 ❌

---

### 2. 처리량 (Throughput)

**의미**: 초당 처리할 수 있는 샘플 수

**단위**: 개/초

**목표값**: 20개/초 이상

**해석**:
- **> 20개/초**: 우수 ✅
- **10-20개/초**: 양호 ⚠️
- **< 10개/초**: 개선 필요 ❌

---

### 3. 품질 통과율 (Quality Pass Rate)

**의미**: 수집된 데이터 중 품질 검증을 통과한 비율

**단위**: 퍼센트 (%)

**목표값**: 90% 이상

**해석**:
- **> 90%**: 우수 ✅
- **70-90%**: 양호 ⚠️
- **< 70%**: 센서 설정 점검 필요 ❌

---

### 4. 라벨링 완료율 (Labeling Rate)

**의미**: 수집된 데이터 중 라벨링이 완료된 비율

**단위**: 퍼센트 (%)

**목표값**: 80% 이상

**해석**:
- **> 80%**: 우수 ✅
- **50-80%**: 양호 ⚠️
- **< 50%**: 라벨링 작업 필요 ❌

## 💡 사용 방법

### 대시보드 접속

1. 웹 브라우저에서 대시보드 접속
   ```
   http://localhost:5000/static/pages/realtime_monitoring_dashboard.html
   ```

2. 성능 지표 섹션 확인
   - 실시간 메트릭 카드에서 성능 지표 확인
   - 차트에서 시간별 추이 확인

3. 디바이스별 성능 확인
   - 디바이스 선택 드롭다운에서 특정 디바이스 선택
   - 해당 디바이스의 성능 지표만 표시

## 📈 성능 최적화 팁

### 처리 시간 개선

1. **모듈화된 시스템 활용**
   - DecibelFilter로 불필요한 연산 스킵
   - 필요한 모듈만 실행

2. **배치 처리**
   - 여러 샘플을 한 번에 처리
   - 네트워크 오버헤드 감소

3. **캐싱 활용**
   - 특징 추출 결과 캐싱
   - 반복 계산 방지

### 처리량 개선

1. **병렬 처리**
   - 여러 디바이스 동시 처리
   - 멀티스레딩 활용

2. **비동기 처리**
   - I/O 작업 비동기화
   - 블로킹 최소화

### 품질 통과율 개선

1. **센서 설정 최적화**
   - 마이크 게인 조정
   - 센서 위치 최적화

2. **전처리 강화**
   - 노이즈 필터링
   - 신호 정규화
