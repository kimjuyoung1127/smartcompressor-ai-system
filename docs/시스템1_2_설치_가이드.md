# 시스템 1 & 2 설치 가이드

## 오류 원인

`ModuleNotFoundError: No module named 'streamlit'` 오류는 다음 중 하나의 원인일 수 있습니다:

1. **패키지 미설치**: 필요한 Python 패키지가 설치되지 않음
2. **환경 불일치**: WSL Linux 환경과 Windows Python 환경이 섞여있음
3. **가상환경 미사용**: 프로젝트별 가상환경이 설정되지 않음

---

## 해결 방법

### 방법 1: requirements.txt로 모든 패키지 설치 (권장)

```bash
# WSL Ubuntu 환경에서 실행
pip install -r requirements.txt

# 또는 특정 패키지만 설치
pip install streamlit>=1.28.0 Pillow>=10.0.0 pandas>=2.0.0 numpy>=1.24.0 matplotlib>=3.7.0
```

### 방법 2: 가상환경 사용 (권장)

```bash
# WSL Ubuntu 환경에서

# 1. 가상환경 생성
python3 -m venv venv

# 2. 가상환경 활성화
source venv/bin/activate

# 3. 패키지 설치
pip install -r requirements.txt

# 4. 시스템 1 실행
streamlit run ai/advanced_labeling_tool.py
```

### 방법 3: Windows에서 직접 실행 (WSL 아닌 경우)

```powershell
# PowerShell에서

# Python 가상환경 생성
python -m venv venv

# 가상환경 활성화
.\venv\Scripts\activate

# 패키지 설치
pip install -r requirements.txt

# Streamlit 실행
streamlit run ai\advanced_labeling_tool.py
```

## WSL vs Windows 환경 문제

### 문제 상황
WSL 경로(`\\wsl.localhost\...`)에서 Windows Python을 실행하려고 하면 환경이 섞일 수 있습니다.

### 해결 방법

**옵션 1: WSL 내부에서 실행**
```bash
# WSL 터미널에서
cd /root/smartcompressor-ai-system
source venv/bin/activate  # 가상환경 활성화
streamlit run ai/advanced_labeling_tool.py
```

**옵션 2: Windows에서 실행**
```powershell
# PowerShell에서 WSL 경로가 아닌 Windows 경로로 접근
# 또는 프로젝트를 Windows 경로로 복사
```

**옵션 3: Docker 사용 (향후)**
Docker 컨테이너로 환경을 완전히 격리
