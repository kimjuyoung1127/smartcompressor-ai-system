## 🔍 커밋 전 확인

### 1. .env 파일 확인

```bash
# .env 파일이 스테이징 영역에 있는지 확인
git status | grep .env

# 있다면 제거
git reset HEAD .env
```

### 2. 민감한 정보 확인

```bash
# 커밋할 파일에서 민감한 정보 검색
git diff --cached | grep -i "password\|secret\|token\|key"
```

### 3. 불필요한 파일 확인

```bash
# 스테이징된 파일 확인
git status --short

# 특정 파일 제외
git reset HEAD <파일명>
```

## ⚠️ 주의사항

1. **절대 커밋하지 말 것**
   - `.env` 파일
   - 데이터베이스 파일 (`*.db`)
   - 로그 파일 (`*.log`)
   - 민감한 정보 (비밀번호, 토큰, 키)

   - `git status`로 변경사항 확인
   - `git diff`로 변경 내용 확인
   - 민감한 정보 검색

3. **의미 있는 커밋 메시지**

   - 왜 변경했는지 설명 (필요시)
