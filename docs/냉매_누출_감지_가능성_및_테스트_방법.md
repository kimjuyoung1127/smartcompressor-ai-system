# 냉매 누출 감지 가능성 및 테스트 방법

## 🎯 핵심 질문

**냉매가 점점 새어 나가는 압축기에서 스펙트럼 이상 점수 방식으로 설치한지 1-2일 만에 이상을 잡을 수 있을까?**

---

## 🔬 냉매 누출의 물리적 특성

### 냉매 누출이 소리에 미치는 영향

#### 1. 압력 변화
- **정상 상태**: 일정한 압력 유지
- **누출 시작**: 압력 점진적 감소
- **소리 변화**: 압축기 작동 소리 변화 (주파수 변화)

#### 2. 주파수 패턴 변화
- **정상**: 일정한 주파수 패턴 (20-200Hz)
- **누출 시작**: 주파수 패턴 변화 (불안정성 증가)
- **고주파 성분**: 마찰음, 진동 증가

#### 3. 에너지 패턴 변화
- **정상**: 일정한 RMS 에너지
- **누출 시작**: RMS 에너지 변동 증가
- **불안정성**: 에너지 변동계수 증가

---

## 📊 스펙트럼 이상 점수 방식의 감지 가능성

### 시나리오 1: 누출이 기준선 설정 전에 시작 (설치 직후)

**상황**:
- 설치 직후 냉매 누출 시작
- 1-2일 기준선 설정 기간 동안 이미 누출 진행 중

**감지 가능성**:
- ⚠️ **어려움**: 기준선 자체가 누출 상태 기준선
- ⚠️ **문제**: 정상 기준선이 아닌 누출 기준선 설정
- ⚠️ **결과**: 누출을 정상으로 인식할 수 있음

**해결 방법**:
- ✅ **다중 기준선**: 여러 시점의 기준선 비교
- ✅ **트렌드 분석**: 시간에 따른 변화 추적
- ✅ **외부 검증**: 온도, 압력 센서와 비교

---

### 시나리오 2: 누출이 기준선 설정 후에 시작 (설치 후 며칠)

**상황**:
- 1-2일 기준선 설정 완료 (정상 상태)
- 그 후 냉매 누출 시작

**감지 가능성**:
- ✅ **가능**: 기준선과 비교하여 즉시 감지 가능
- ✅ **정확도**: 높음 (정상 기준선과 명확한 차이)
- ✅ **속도**: 즉시 감지 (누출 시작 후 몇 시간 내)

**감지 방법**:
```python
# 기준선 설정 (정상 상태)
baseline = establish_baseline(normal_samples)  # 1-2일 수집

# 누출 시작 후
current_features = extract_features(audio_data)
anomaly_score = calculate_anomaly_score(current_features, baseline)

# 냉매 누출 특징
if (anomaly_score > 0.7 and 
    current_features['low_freq_ratio'] > baseline['low_freq_ratio_mean'] + 2*std and
    current_features['spectral_centroid_std'] > baseline['spectral_centroid_std'] * 1.5):
    detect_refrigerant_leak()
```

### 시나리오 3: 점진적 누출 (매우 느린 누출)

**상황**:
- 매우 느린 누출 (수주~수개월)
- 하루 단위로는 변화가 미미

**감지 가능성**:
- ⚠️ **어려움**: 하루 단위로는 변화가 미미
- ⚠️ **필요**: 장기 트렌드 분석 필요
- ⚠️ **해결**: 시계열 분석, 트렌드 추적

**해결 방법**:
```python
# 장기 트렌드 분석
def detect_gradual_leak(history: List[Dict], baseline: Dict) -> bool:
    """
    점진적 누출 감지 (장기 트렌드 분석)
    """
    # 최근 7일 데이터
    recent_features = history[-7:]
    
    # 트렌드 분석
    trend = calculate_trend(recent_features, 'low_freq_ratio')
    
    # 점진적 증가 감지
    if trend > 0.05:  # 5% 이상 증가
        return True
    
    return False
```

## 🎯 실제 감지 가능성 평가

### 즉시 감지 가능 (누출 시작 후 몇 시간 내)

**조건**:
- ✅ 기준선 설정 완료 (정상 상태)
- ✅ 누출이 기준선 설정 후 시작
- ✅ 누출 속도가 빠름 (하루에 10% 이상)

**감지 방법**:
- 스펙트럼 이상 점수 > 0.7
- 저주파 에너지 비율 증가
- 스펙트럼 중심 변동 증가

**정확도**: **75-85%**

---

### 장기 트렌드 분석 필요 (점진적 누출)

**조건**:
- ⚠️ 매우 느린 누출 (수주~수개월)
- ⚠️ 하루 단위로는 변화가 미미

**감지 방법**:
- 시계열 분석
- 트렌드 추적
- 다중 기준선 비교

**정확도**: **60-75%** (장기 데이터 필요)
