# 하이브리드 저장 구현 가이드

## 🔍 질문 답변 요약

### Q1: 샘플링 간격과 파일 용량
**답변**: 한 개 파일 용량은 동일 (160 KB), 하지만 수집 횟수가 다름
- 60초 간격: 1,440개/일 → 230.4 MB/일
- 5분 간격: 288개/일 → 46.1 MB/일

### Q2: 전체 녹음본인가?
**답변**: 아니요. 5초 샘플만 주기적으로 수집합니다.

### Q3: 로컬 저장 장치 설치 필요?
**답변**: 아니요. EC2 서버의 디스크(EBS)에 저장되므로 별도 설치 불필요.

## 💾 하이브리드 저장 서비스 구현

### 핵심 기능

1. **이상 감지 시**: 오디오 파일 + 분석 결과 + 특징 데이터 저장
2. **정상 데이터**: 통계만 저장 (용량 절감)
3. **AI 학습 최적화**: 불확실한 데이터, Edge case 우선 수집

### 저장 조건

```python
# 저장되는 경우
- 이상 감지 (confidence > 0.7)
- 신뢰도 낮음 (confidence < 0.6)  # AI 학습에 중요
- 품질 낮음 (quality < 30)

# 저장되지 않는 경우
- 정상 데이터 (통계만 업데이트)
```

## 📊 예상 비용 (하이브리드 저장)

### 가정
- 센서 2개
- 샘플링 간격: 5분 (288 샘플/일)
- 이상 발생률: 5% (14.4개/일)
- 오디오 파일: MP3 압축 (약 20 KB/파일)

### 계산
```
일일 이상 샘플: 14.4개
오디오 파일: 14.4 × 20 KB = 288 KB/일
분석 결과: 14.4 × 2 KB = 28.8 KB/일
특징 데이터: 14.4 × 1 KB = 14.4 KB/일
정상 통계: 273.6 × 0.1 KB = 27.4 KB/일 (10% 샘플링)
─────────────────────────────
총 용량: 358.6 KB/일
월간 용량: 10.8 MB/월
```

### 비용
```
EBS 스토리지: 10.8 MB × $0.08/GB = $0.0009/월
EC2: $7.49/월 (프리티어 무료 가능)
─────────────────────────────
총계: $0.0009-7.50/월
```

**거의 무료!** 🎉
