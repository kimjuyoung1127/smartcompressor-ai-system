# WAV vs MP3 비교 분석 - 소리 전문 기업 관점

## 📊 기술적 차이

### WAV (Waveform Audio File Format)

**특징**:
- ✅ **무손실 압축** (Lossless)
- ✅ **원본 품질 보존** (100% 원본과 동일)
- ✅ **압축 없음** (PCM 원시 데이터)
- ❌ **용량이 큼** (약 10MB/분, 16kHz 모노)
- ✅ **처리 속도 빠름** (압축/해제 불필요)
- ✅ **표준 형식** (모든 오디오 분석 도구 지원)

**용량 계산**:
```
16,000 samples/sec × 2 bytes × 60 sec = 1.92 MB/분
5초 샘플 = 160 KB
```

---

### MP3 (MPEG Audio Layer 3)

**특징**:
- ✅ **손실 압축** (Lossy)
- ⚠️ **품질 손실** (압축률에 따라 다름)
- ✅ **용량이 작음** (약 1MB/분, 128kbps)
- ❌ **처리 속도 느림** (압축/해제 필요)
- ✅ **표준 형식** (대부분의 도구 지원)

**용량 계산** (128kbps 기준):
```
128 kbps × 60 sec / 8 bits = 960 KB/분
5초 샘플 = 80 KB (WAV 대비 50% 절감)
```

**압축률별 비교**:
- 64kbps: 40 KB/5초 (75% 절감, 품질 낮음)
- 128kbps: 80 KB/5초 (50% 절감, 품질 중간)
- 192kbps: 120 KB/5초 (25% 절감, 품질 높음)

## 🎯 소리 전문 기업 관점에서의 고려사항

### 1. 데이터 품질 (가장 중요)

#### WAV의 장점
- ✅ **원본 품질 보존**: 모든 주파수 정보 유지
- ✅ **정밀한 분석 가능**: 고주파 성분까지 정확히 분석
- ✅ **재분석 가능**: 나중에 다른 알고리즘으로 재분석 가능
- ✅ **학술적 가치**: 논문, 연구에 사용 가능

#### MP3의 단점
- ❌ **주파수 손실**: 고주파 성분 제거 (20kHz 이상)
- ❌ **압축 아티팩트**: 압축 과정에서 발생하는 노이즈
- ❌ **재분석 제한**: 압축된 데이터로는 정밀 분석 어려움

**소리 전문 기업이라면**: 품질이 최우선이므로 **WAV가 유리**

---

### 2. 비용 효율성

#### WAV 비용
```
센서 2개, 5분 간격, 이상 발생률 5%
일일 이상 샘플: 14.4개
용량: 14.4 × 160 KB = 2.3 MB/일
월간: 69 MB/월
비용: $0.0055/월
```

#### MP3 비용 (128kbps)
```
일일 이상 샘플: 14.4개
용량: 14.4 × 80 KB = 1.15 MB/일
월간: 34.5 MB/월
비용: $0.0028/월
```

**비용 차이**: 거의 무시할 수준 ($0.0027/월 차이)

**소리 전문 기업이라면**: 비용보다 품질이 우선

---

### 3. 확장성

#### 장기적 관점
- **센서 10개**: WAV 345 MB/월, MP3 172.5 MB/월
- **센서 100개**: WAV 3.45 GB/월, MP3 1.73 GB/월
- **센서 1,000개**: WAV 34.5 GB/월, MP3 17.3 GB/월

**비용 차이** (1,000개 센서):
- WAV: $2.76/월
- MP3: $1.38/월
- **차이: $1.38/월** (여전히 작음)

**소리 전문 기업이라면**: 확장 시에도 비용 차이는 크지 않음

---

### 4. 기술적 신뢰성

#### WAV
- ✅ **표준 형식**: 모든 오디오 분석 라이브러리 지원
- ✅ **호환성**: librosa, scipy, numpy 모두 완벽 지원
- ✅ **안정성**: 압축/해제 과정 없어 오류 가능성 낮음

#### MP3
- ⚠️ **추가 라이브러리 필요**: pydub, ffmpeg 등
- ⚠️ **의존성 증가**: 외부 도구 필요
- ⚠️ **호환성 이슈**: 일부 환경에서 문제 가능

**소리 전문 기업이라면**: 기술적 신뢰성이 중요하므로 **WAV가 유리**

---

### 5. 학술적/상업적 가치

#### WAV
- ✅ **논문 발표 가능**: 원본 데이터로 통계적 검증 가능
- ✅ **재현 가능성**: 다른 연구자가 동일한 데이터로 재현 가능
- ✅ **상업적 가치**: 고품질 데이터셋으로 판매 가능

#### MP3
- ❌ **학술적 제한**: 손실 압축으로 인한 검증 한계
- ❌ **재현 어려움**: 압축 과정에서 정보 손실
- ⚠️ **상업적 가치 낮음**: 손실 데이터는 가치가 낮음

**소리 전문 기업이라면**: 데이터 자산의 가치가 중요하므로 **WAV가 필수**

## 💡 하이브리드 접근법 (권장)

### 전략: 용도별 형식 선택

#### 1. 이상 데이터: WAV 저장 (원본 보존)
```python
if is_anomaly:
    # WAV 형식으로 저장 (원본 품질)
    save_as_wav(audio_data)
```

**이유**:
- 이상 데이터는 재분석이 중요
- 고주파 성분 분석 필요
- 학술적/상업적 가치

#### 2. 정상 데이터: 저장하지 않음 (통계만)
```python
if normal:
    # 오디오 파일 저장하지 않음
    # 통계만 업데이트
    update_statistics()
```

**이유**:
- 정상 데이터는 대부분 불필요
- 통계만으로 충분
- 용량 절감

#### 3. 불확실한 데이터: WAV 저장 (AI 학습용)
```python
if confidence < 0.6:
    # WAV 형식으로 저장
    save_as_wav(audio_data)
```

**이유**:
- AI 학습에 중요
- 정밀한 분석 필요
- 전문가 라벨링 후 학습
