# 가상환경 설정 가이드

## 문제 상황

Python 3.12+ 환경에서 시스템 레벨 패키지 설치 시 다음 오류가 발생합니다:

```
error: externally-managed-environment
```

이는 PEP 668에 따라 시스템 Python을 보호하기 위한 조치입니다.

---

## 해결 방법: 가상환경 사용

### 1단계: 가상환경 생성

```bash
# 프로젝트 루트 디렉토리에서
cd /root/smartcompressor-ai-system

# 가상환경 생성
python3 -m venv venv
```

만약 `python3-venv` 패키지가 없으면:
```bash
sudo apt update
sudo apt install python3-venv python3-full
```

### 2단계: 가상환경 활성화

```bash
source venv/bin/activate
```

활성화되면 프롬프트 앞에 `(venv)`가 표시됩니다:
```
(venv) root@DESKTOP-RS7MU4F:~/smartcompressor-ai-system#
```

### 3단계: 패키지 설치

```bash
# 필수 패키지 설치
pip install streamlit>=1.28.0 Pillow>=10.0.0 pandas numpy matplotlib scipy scikit-learn

# 또는 requirements.txt 전체 설치
pip install -r requirements.txt
```

### 4단계: 실행

```bash
# 시스템 1 실행
streamlit run ai/advanced_labeling_tool.py

# 시스템 2 데모 실행
python scripts/run_system1_system2_demo.py
```

### 5단계: 가상환경 비활성화 (선택적)

```bash
deactivate
```

## 빠른 설치 스크립트 사용

### 자동 설치 스크립트 실행

```bash
# WSL/Linux에서
bash scripts/install_system1_system2.sh
```

이 스크립트는:
1. 가상환경이 없으면 자동 생성
2. 가상환경 활성화
3. 필수 패키지 설치
4. 설치 확인

## 가상환경이 이미 있는 경우

```bash
# 가상환경 활성화만 하면 됩니다
source venv/bin/activate

# 패키지 설치
pip install -r requirements.txt
```

## 문제 해결

### 가상환경 생성 실패

```bash
# python3-venv 패키지 설치
sudo apt update
sudo apt install python3-venv python3-full
```

### 가상환경 활성화 후에도 패키지를 찾을 수 없음

```bash
# 가상환경이 제대로 활성화되었는지 확인
which python
# 출력: /root/smartcompressor-ai-system/venv/bin/python

# pip 위치 확인
which pip
# 출력: /root/smartcompressor-ai-system/venv/bin/pip
```

### 시스템 패키지와 충돌

가상환경을 사용하면 시스템 패키지와 완전히 분리되므로 충돌이 없습니다.

## 권장 워크플로우

### 매일 작업 시작 시

```bash
cd /root/smartcompressor-ai-system
source venv/bin/activate
```

### 새 터미널 창에서 작업할 때

항상 가상환경을 활성화해야 합니다:
```bash
source venv/bin/activate
```

### 작업 종료 시 (선택적)

```bash
deactivate
```

## Git에 가상환경 포함하지 않기

`.gitignore`에 다음이 포함되어 있는지 확인:
```
venv/
*.pyc
__pycache__/
```

## 요약

1. ✅ 가상환경 생성: `python3 -m venv venv`
2. ✅ 가상환경 활성화: `source venv/bin/activate`
3. ✅ 패키지 설치: `pip install -r requirements.txt`
4. ✅ 실행: `streamlit run ai/advanced_labeling_tool.py`

**중요**: 가상환경이 활성화된 상태(`(venv)` 프롬프트 표시)에서만 실행하세요!
