# 빠른 시작 가이드

## 🚀 5분 안에 시작하기

### 방법 1: Docker 사용 (가장 빠름)

```bash
# 1. 저장소 클론
git clone https://github.com/SEONBEOM-Kim/smartcompressor-ai-system.git
cd smartcompressor-ai-system

# 2. 환경 변수 설정
cp env.example .env

# 3. 실행
docker-compose up -d

# 4. 확인
curl http://localhost:5000/api/health
```

**완료!** 🎉

### 시나리오 2: 기존 서비스에 기능 추가

```bash
# 1. 필요한 파일 복사
cp -r services/anomaly_detection_modules/ your-project/services/
cp services/esp32_integrated_detection_service.py your-project/services/
cp routes/esp32_integrated_routes.py your-project/routes/

# 2. 의존성 설치
pip install -r requirements.txt

# 3. 라우트 등록 (app.py)
from routes.esp32_integrated_routes import esp32_integrated_bp
app.register_blueprint(esp32_integrated_bp, url_prefix='/api/esp32')

# 4. 테스트
pytest tests/ -v
```

---

### 시나리오 3: 새 프로젝트 시작

```bash
# 1. 프로젝트 생성
mkdir my-project
cd my-project

# 2. 핵심 파일 복사
cp -r smartcompressor-ai-system/services/anomaly_detection_modules/ services/
cp smartcompressor-ai-system/services/esp32_integrated_detection_service.py services/
cp smartcompressor-ai-system/routes/esp32_integrated_routes.py routes/

# 3. 의존성 설치
pip install flask numpy librosa scikit-learn

# 4. 앱 생성 (app.py)
from flask import Flask
from routes.esp32_integrated_routes import esp32_integrated_bp

app = Flask(__name__)
app.register_blueprint(esp32_integrated_bp, url_prefix='/api/esp32')

if __name__ == '__main__':
    app.run(port=5000)

# 5. 실행
python app.py
```

## 🔧 필수 명령어

### 개발

```bash
# 서버 실행
python app.py

# 테스트 실행
pytest tests/ -v

# 특정 테스트만
pytest tests/test_anomaly_detection_modules/ -v

# 커버리지 확인
pytest tests/ --cov=services --cov-report=html
```

### Docker

```bash
# 시작
docker-compose up -d

# 중지
docker-compose down

# 로그 확인
docker-compose logs -f

# 재빌드
docker-compose up -d --build
```
