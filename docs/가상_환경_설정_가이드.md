# 가상 환경 설정 및 테스트 실행 가이드

## 🚀 빠른 시작 (WSL 터미널에서 실행)

### 1단계: 가상 환경 생성

```bash
cd ~/smartcompressor-ai-system

# 가상 환경 생성
python3 -m venv venv
```

### 2단계: 가상 환경 활성화

```bash
source venv/bin/activate
```

활성화되면 프롬프트 앞에 `(venv)`가 표시됩니다:
```
(venv) root@DESKTOP-RS7MU4F:~/smartcompressor-ai-system#
```

### 3단계: pytest 설치

```bash
# pip 업그레이드
pip install --upgrade pip

# pytest 설치
pip install pytest pytest-cov pytest-asyncio

# 또는 requirements.txt에서 모두 설치
pip install -r requirements.txt
```

### 4단계: 테스트 실행

```bash
# 모든 테스트 실행
pytest tests/

# 상세 출력
pytest tests/ -v

# 커버리지 포함
pytest tests/ --cov=services/anomaly_detection_modules --cov-report=html
```

## 📝 한 번에 실행 (복사해서 붙여넣기)

```bash
cd ~/smartcompressor-ai-system && \
```

가상 환경은 한 번만 생성하면 됩니다. 다음번에는:

## 🐛 문제 해결

### 문제: "python3-venv 패키지가 없습니다"

**해결 방법:**
```bash
sudo apt update
sudo apt install python3-venv
```

### 문제: "가상 환경 활성화가 안 됩니다"

**해결 방법:**
```bash
# 스크립트로 실행
source venv/bin/activate

# 또는 직접 경로 지정
./venv/bin/pytest tests/
```

---

## 💡 팁

1. **가상 환경 활성화 확인**: 프롬프트 앞에 `(venv)`가 보이면 활성화된 것입니다.

2. **가상 환경 비활성화**: `deactivate` 명령어 사용

3. **가상 환경 재생성**: `rm -rf venv` 후 다시 생성
