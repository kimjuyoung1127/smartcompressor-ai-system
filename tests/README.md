# tests/ 디렉토리

이 디렉토리는 프로젝트의 모든 테스트 파일들을 포함합니다. 자동화 테스트, 유닛 테스트, 통합 테스트 등 다양한 테스트 파일들이 위치합니다.

## 포함된 파일

- `test_admin_system.py` - 관리자 시스템 테스트
- `test_ai_model.py` - AI 모델 테스트
- `test_analytics_system.py` - 분석 시스템 테스트
- `test_auto_pipeline.py` - 자동화 파이프라인 테스트
- `test_complete_system.js` - 완전한 시스템 테스트
- `test_dashboard_system.py` - 대시보드 시스템 테스트
- `test_iot_system.py` - IoT 시스템 테스트
- `test_lightweight_3tier_system.js` - 경량 3티어 시스템 테스트
- `test_mobile_app.py` - 모바일 앱 테스트
- `test_mobile_app_system.py` - 모바일 앱 시스템 테스트
- `test_notification_system.py` - 알림 시스템 테스트
- `test_phase1_api.js` - 1단계 API 테스트
- `test_safe_gpu_system.py` - GPU 시스템 테스트
- `test_sensor.js` - 센서 테스트

## 목적

이 디렉토리는 소스 코드와 테스트 코드를 분리하여, 코드 베이스의 유지보수성을 높이고 테스트 실행을 용이하게 하기 위함입니다. 테스트 파일들을 한 곳에 모아 관리함으로써, 프로젝트의 신뢰성과 품질 보증을 강화합니다.
