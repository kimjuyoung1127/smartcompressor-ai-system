# web/ 디렉토리

이 디렉토리는 웹 인터페이스와 관련된 HTML 파일들을 포함합니다. 프론트엔드 웹 자산은 static 디렉토리에 위치하며, 이 디렉토리는 주로 HTML 파일들을 저장합니다.

## 포함된 파일

- `audio_research.html` - 오디오 연구 페이지
- `audio_research_features.html` - 오디오 연구 기능 페이지
- `audio_research_fixed.html` - 수정된 오디오 연구 페이지
- `backend.html` - 백엔드 인터페이스 페이지
- `index.html` - 메인 인덱스 페이지
- `showcase.html` - 쇼케이스 페이지
- `진단리포트_다농마트_20250812_113007.html` - 진단 리포트 파일

## 목적

이 디렉토리는 웹 인터페이스의 구조를 명확히 하기 위해 HTML 파일들을 별도로 관리합니다. 이는 템플릿 엔진(templates/)과 정적 자산(static/)과 구분되며, 순수한 웹 인터페이스 파일들을 포함합니다.
